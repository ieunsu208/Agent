# 가상 클라이언트 인터뷰 기반 UX/UI 분석 스킬 (인터뷰_skill.md)

---

## 0. 담당 역할 및 개요
* **담당 역할:** 타깃 페르소나 및 이커머스 FGI 분석을 통한 사용자 경험(UX) 요구사항 도출
* **분석 대상 문서:** `가상 클라이언트/인터뷰.md`
* **주요 목적:** 6인 페르소나별 니즈와 FGI 구매 여정 상의 Pain Point를 파악하여 이커머스 UI/UX 개선안 및 기능 명세 자동 생성

---

## 2. FGI 이커머스 구매 여정 개선 가이드라인

1. **UI/UX 동선 파편화 해결:**
   - **찜/장바구니 선택 UI 일관성:** 앱 전체에서 통일된 체크박스 및 1-클릭 다중 삭제 기능 제공.
   - **뒤로가기 스크롤 리셋 방지:** 이전 목록 탐색 시 스크롤 위치 유지(Scroll Restoration) 및 직전에 보던 필터 상태 보존.
2. **구매 의사결정 정보 보완:**
   - **품절 & 가격 변동 알림:** 품절 상품 발생 시 대체 상품 자동 추천 팝업 및 실시간 가격 변동 알림 UI 배치.
   - **직관적 향/사이즈 정보 전달:** 감성적인 추상 문구(햇살, 이슬 등) 대신 실제 잔향 노트 피라미드, 용량별 착용/휴대 크기 비교 픽토그램, 샘플 키트 증정 CTA 구성.

---

## 3. UX 분석 및 기능 도출 프로세스

1. **페르소나 매칭:** 대상 사용자 타깃을 6대 페르소나 중 선택하거나 조합하여 사용자 여정(Customer Journey) 수립.
2. **Pain Point 변환:** 사용자의 불편사항을 '기능적 요구사항(Functional Needs)'과 '시각적 요구사항(Visual Needs)'으로 격상.
3. **상세페이지 스펙 설계:** 
   - 감성 이미지와 객관적 구매 후기/통계 그래픽의 50:50 균형 배치.
   - 샘플 체험 키트 1-Click 신청 버튼 및 선물하기 전용 메시지 카드 커스텀 UI 추가.

## 4. 완료 전 검사 및 응답 규칙

- [ ] 6인 페르소나의 Pain Point와 Needs가 UI 기능으로 명확히 매핑되었는가?
- [ ] FGI 이커머스 불편사항(스크롤 리셋, 장바구니 UI, 정보 불확실성)에 대한 솔루션이 포함되었는가?
- [ ] 객관적 성분/후기 데이터와 브랜드 감성 비주얼이 균형 있게 제시되었는가?

검사가 완료되면 페르소나 기반 UX 개선 보고서를 생성하고 작업을 마무리한다.
