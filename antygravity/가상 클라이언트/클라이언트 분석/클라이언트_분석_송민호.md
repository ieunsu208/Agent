## 1. 가상 클라이언트의 기본 정보 설정
- **프로젝트 중심 주제:** 사단(士團) 성수 팝업스토어 사전예약 및 백꾸 마패 키체인 굿즈 스토어
- **제작 목적:** 팝업 방문 유도, 백꾸 트렌드 유저층 흡수, 굿즈 즉시 구매 전환
- **클라이언트 제공 자료:** 팝업 타임슬롯 데이터, 백꾸 참 이미지 자산, 룩북 포토 데이터
- **필요한 정보와 기능:** 팝업 사전예약 폼, QR 티켓, 백꾸 가상 코디 시뮬레이터, 소셜 룩북 그리드, 실시간 재고 타이머
- **중요도 및 작업 우선순위:** 팝업 예약 & 백꾸 시뮬레이터(최우선) ➔ 소셜 룩북 & 굿즈 구매(우선) ➔ 재고 타이머(보통)
- **적용 매체:** Mobile First Responsive Web

## 4. 비슷한 항목끼리 분류 (그룹화)
- **그룹 A (팝업 연동):** 사전예약 폼, QR 티켓, 오프라인 팝업 위치 지도, 현장 쿠폰
- **그룹 B (백꾸 커스터마이징):** 백꾸 가상 코디 툴, 마패 참 파우치, 노리개 스트랩 옵션
- **그룹 C (소셜 커머스):** 인스타그램 룩북 갤러리, 굿즈 Quick Add Cart, 실시간 재고 카운트다운

```text
사단(士團) 송민호 클라이언트 웹사이트
├─ 1. Pop-up Reservation (팝업 예약)
│  ├─ 성수/삼청 팝업스토어 위치 & 일정
│  ├─ 타임슬롯별 사전예약 신청
│  └─ 모바일 QR 익스프레스 입찰 패스
├─ 2. Bag-decor Studio (백꾸 스튜디오)
│  ├─ 백꾸 마패 참 2D 가상 착용 시뮬레이터
│  ├─ 노리개 스트랩 & 태슬 조합 옵션
│  └─ 내 백꾸 코디 이미지 저장 & 공유
├─ 3. Limited Goods (한정판 굿즈)
│  ├─ 팝업 한정 1·2·3마패 키체인 향수
│  ├─ 조선 전통 놋쇠 참 모듈
│  └─ 실시간 재고 잔여 수량 카운터
├─ 4. Social Lookbook (소셜 룩북)
│  ├─ 인스타그램 유저 백꾸 스타일 그리드
│  └─ 이미지 클릭 시 굿즈 Quick Add Cart
└─ 5. Event & Coupon (이벤트)
   └─ 첩보 시향 킷 현장 수령 QR 쿠폰
```

## 6. 내비게이션 연결 (Navigation Flow)
- **시작 화면:** 팝업 론칭 카운트다운 타이머 + 백꾸 비주얼 타일 갤러리
- **주요 동선:** 메인 ➔ Pop-up Reservation ➔ 날짜 선택 ➔ QR 티켓 발급
- **보조 동선:** 메인 ➔ Bag-decor Studio ➔ 가상 코디 ➔ 장바구니 담기

5. **Footer:** 팝업 주소, CS Center, 인스타그램 계정 링크
