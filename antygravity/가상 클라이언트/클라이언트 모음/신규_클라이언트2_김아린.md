# 신규 클라이언트 2: 김아린 (사단 웰니스 & 힐링 디퓨저 수석 연구원) UI/UX 분석 보고서

### 📌 9단계 가상 클라이언트 분석 프로세스

#### 1) 기본 정보 설정
- **프로젝트 주제:** 한옥 공간 맞춤형 아로마 스마트 디퓨저 '사단 웰니스' 자사몰 웹사이트 기획
- **제작 목적:** 공간 맞춤 힐링 디퓨저 론칭 안내, 스마트 디바이스 정기구독 사전 신청자 모집
- **제공 자료:** 클라이언트 브리프, 뇌파/숙면 임상 데이터, 디바이스 사양서
- **필요 정보/기능:** 공간별(침실, 서재, 거실) 향 매칭 테스트 UI, 스마트 타이머 디바이스 소개, 웰니스 리필 정기구독 신청
- **작업 우선순위:** ① 공간별 향 매칭 테스트 → ② 스마트 디퓨저 디바이스 소개 → ③ 리필 정기구독 신청 → ④ 뇌파 검증 데이터
- **적용 매체:** 웹 (PC/모바일 반응형)

#### 2) 클라이언트가 원하는 항목 수집
| 번호 | 클라이언트 요청 내용 | 관련 자료 | 중요도 |
| :---: | :--- | :--- | :---: |
| 1 | 침실/서재/거실 등 공간별 최적 오리엔탈 향 매칭 테스트 UI | 테스트 기획서 | 높음 |
| 2 | 스마트폰 앱으로 발향 농도 및 타이머를 조절하는 디바이스 소개 | 디바이스 사양 | 높음 |
| 3 | 뇌파 안정 및 숙면 효과 임상 검증 수치 및 그래프 공개 | 임상 데이터 | 높음 |
| 4 | 매월 계절별 아로마 카트리지가 배송되는 정기구독 신청 폼 | 구독 서비스안 | 높음 |
| 5 | 무상 아로마 시향 캡슐 4종 체험 키트 신청 팝업 | 마케팅 이벤트 | 보통 |

| 숙면 임상 데이터 | 사실 | 신뢰성 | 뇌파 검증 | Clinical Science | 뇌파 그래프, 검증 배지 |

#### 4) 비슷한 항목끼리 분류
- **그룹 1 (웰니스 비주얼):** 한옥 대청마루와 아침 햇살 비디오 히어로, 힐링 사운드
- **그룹 2 (공간 매칭 & 테스트):** 침실/서재/거실 공간 매칭 퀴즈 UI, 향 추천 카드
- **그룹 3 (스마트 디바이스):** App 연동 스마트 발향 디바이스 뷰어, 사용법 애니메이션
- **그룹 4 (임상 & 구독):** 뇌파 임상 수치 그래프, 매월 리필 정기구독 신청 폼

#### 5) 계층 구조 작성 (Information Architecture)
```text
사단 웰니스 자사몰
├─ 1. Wellness Philosophy (힐링 철학)
│  ├─ 한옥 공간과 후각 웰니스 서사
│  └─ 마음 정화 아침 햇살 영상
├─ 2. Scent Test (공간 향 매칭)
│  ├─ 침실, 서재, 거실 공간별 1분 테스트
│  └─ 나만의 힐링 아로마 레시피 추천
├─ 3. Smart Device (스마트 디퓨저)
│  ├─ App 연동 발향 농도 & 타이머 제어
│  └─ 영구 사용 한옥 기와 디자인 디바이스
└─ 4. Subscription (정기구독)
   ├─ 매월 계절별 카트리지 정기 배송 플랜
   └─ 4종 아로마 시향 캡슐 무료 신청
```

#### 6) 사용자가 이해하기 쉬운 이름 부여 (레이블링)

- `Scent Test`: 공간별 맞춤 향을 찾아주는 테스트 명칭
- `Smart Device`: 디바이스 기능성과 App 연동을 알리는 레이블
- `Subscription`: 매월 카트리지 정기구독 혜택을 명확히 제시

### 📝 6대 필수 작성 양식

#### 1. 가상 클라이언트
- **프로젝트 주제:** 한옥 공간 맞춤형 아로마 스마트 디퓨저 '사단 웰니스' 자사몰 기획
- **제작 목적:** 공간 맞춤 디퓨저 론칭 및 스마트 카트리지 정기구독 사전 신청 유치
- **제공 자료:** 클라이언트 브리프, 뇌파/숙면 임상 데이터, 디바이스 사양서
- **적용 매체:** 웹 (PC/모바일 반응형)

#### 2. 클라이언트 요구사항
- **요청 항목:** 공간 향 매칭 테스트 UI, 스마트 발향 디바이스 안내, 뇌파 임상 수치 공개, 리필 정기구독 신청 폼
- **중요도:** 향 매칭 테스트(높음), 정기구독 신청(높음), 디바이스 안내(높음), 임상 수치(보통)
- **관련 자료:** 신규 클라이언트 2 브리프
- **필요한 기능:** 1분 퀴즈 테스트 UI, 3D 디바이스 뷰어, 뇌파 수치 그래프, 구독 플랜 신청 폼

#### 3. 정보 구조
- **주제:** 한옥의 단정함과 스마트 기술이 결합된 공간 아로마 웰니스
- **부주제:** 공간 향 매칭, 스마트 앱 제어, 카트리지 정기 배송
- **메뉴:** Wellness Philosophy, Scent Test, Smart Device, Subscription
- **콘텐츠:** 힐링 비디오, 퀴즈 UI, 3D 뷰어, 임상 그래프, 신청 폼
- **정보 유형:** 개념 (웰니스 서사), 사실 (디바이스 사양, 임상 데이터), 과정 (향 매칭), 절차 (정기구독)

#### 4. 내비게이션
- **시작 화면:** 아침 햇살과 한옥 대청마루 비디오 히어로
- **이동 경로:** 히어로 → 공간 향 매칭 테스트 → 스마트 디바이스 안내 → 뇌파 데이터 → 구독 신청
- **연결 페이지:** [테스트 결과] → 정기구독 신청 폼에 추천 카트리지 자동 세팅
- **검색 및 위치 안내:** 상단 GNB 및 우하단 시향 캡슐 스티키 바

- **보조 콘텐츠 (어사이드):** 우하단 [4종 시향 캡슐 신청] 스티키 뱃지

#### 6. 검토 결과
- **누락 항목:** 없음
- **중복 항목:** 숙면 임상 설명을 요약 그래프 하나로 명확히 시각화
- **사용자 관점의 개선점:** 퀴즈 테스트 문항을 3개로 단순화하여 사용자 이탈 최소화
