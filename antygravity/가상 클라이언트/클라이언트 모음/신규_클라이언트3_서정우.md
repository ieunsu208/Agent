### 📌 9단계 가상 클라이언트 분석 프로세스

#### 1) 기본 정보 설정
- **프로젝트 주제:** 장인 수제 가죽 마패 키링 커스텀 플랫폼 '사단 아틀리에' 웹사이트 기획
- **제작 목적:** 수제 가죽 마패 키링 100% 주문 제작 플랫폼 론칭 및 B2B 기업 기프트 견적 신청 유치
- **제공 자료:** 가죽 아틀리에 브리프, 가죽 종류/컬러 샘플, 3D 각인 가이드
- **필요 정보/기능:** 3D 가죽 색상/각인 커스텀 시뮬레이터, 가죽 장인 공방 비하인드, B2B 대량 주문 견적 폼
- **작업 우선순위:** ① 3D 실시간 가죽 커스텀 시뮬레이터 → ② B2B 대량 기프트 견적 신청 → ③ 가죽/각인 룩북 → ④ 장인 인터뷰
- **적용 매체:** 웹 (PC/모바일 반응형)

#### 2) 클라이언트가 원하는 항목 수집
| 번호 | 클라이언트 요청 내용 | 관련 자료 | 중요도 |
| :---: | :--- | :--- | :---: |
| 1 | 이탈리안 가죽 컬러와 한글/영문 붓글씨 각인 3D 시뮬레이션 UI | 커스텀 기획서 | 높음 |
| 2 | 기업 및 단체 고객을 위한 B2B 대량 맞춤 기프트 견적 신청 폼 | B2B 사업안 | 높음 |
| 3 | 40년 경력 전통 가죽 장인의 핸드스티치 제작 과정 비디오 | 공방 인터뷰 | 보통 |
| 4 | 이탈리아 베지터블 가죽 인증서 및 에이징 질감 룩북 | 원피 인증서 | 보통 |
| 5 | 개인 맞춤 1:1 이니셜 각인 샘플 및 고급 선물 포장 안내 | 패키지 가이드 | 보통 |

#### 4) 비슷한 항목끼리 분류
- **그룹 1 (커스텀 비주얼):** 3D 실시간 가죽/각인 커스텀 시뮬레이터 UI
- **그룹 2 (장인 정신 & 소재):** 가죽 장인 핸드스티치 비디오, 이탈리아 베지터블 가죽 인증
- **그룹 3 (B2B 견적 문의):** B2B 기업 기프트 대량 수량 견적 신청 폼, 로고 샘플
- **그룹 4 (패키지 & 선물):** 수제 오리엔탈 한지 기프트 박스 및 쇼핑백 안내

#### 5) 계층 구조 작성 (Information Architecture)
```text
사단 커스텀 아틀리에
├─ 1. Customizer (3D 커스텀)
│  ├─ 실시간 가죽 컬러 & 3D 이니셜 각인
│  └─ 나만의 마패 키링 완성 샷 다운로드
├─ 2. Atelier Craft (장인 공방)
│  ├─ 40년 가죽 장인 핸드스티치 비하인드
│  └─ 베지터블 가죽 시간 경과 에이징 룩북
├─ 3. B2B Bulk Order (기업 기프트)
│  ├─ 기업 로고 불박 각인 샘플
│  └─ B2B 대량 주문 1:1 맞춤 견적 신청
└─ 4. Packaging (선물 포장)
   ├─ 한지 지함 기프트 박스 packaging
   └─ 무료 붓글씨 메시지 카드 서비스
```

#### 6) 사용자가 이해하기 쉬운 이름 부여 (레이블링)
- `Customizer`: 직관적으로 3D 실시간 키링 조합을 만들어보는 레이블
- `Atelier Craft`: 수공예 장인 정신과 가죽 소재의 가치를 전달
- `B2B Bulk Order`: 기업 대량 주문 고객을 위한 전용 메뉴
- `Packaging`: 선물용 기프트 포장 옵션을 부각하는 레이블

#### 7) 내비게이션 연결

### 📝 6대 필수 작성 양식

#### 1. 가상 클라이언트
- **프로젝트 주제:** 장인 수제 가죽 마패 키링 커스텀 플랫폼 '사단 아틀리에' 기획
- **제작 목적:** 100% 수제 가죽 키링 커스텀 제작 지원 및 B2B 기업 기프트 수주 유치
- **제공 자료:** 가죽 아틀리에 브리프, 원피 샘플, 3D 각인 가이드
- **적용 매체:** 웹 (PC/모바일 반응형)

#### 2. 클라이언트 요구사항
- **요청 항목:** 3D 실시간 가죽/각인 커스텀 시뮬레이터, B2B 대량 주문 견적 폼, 장인 비하인드 비디오, 패키지 안내
- **중요도:** 3D 커스텀 시뮬레이터(높음), B2B 견적 폼(높음), 장인 비디오(보통)
- **관련 자료:** 신규 클라이언트 3 브리프
- **필요한 기능:** 3D 실시간 뷰어, 텍스트 각인 프리뷰, B2B 수량별 계산기, 견적 신청 폼

#### 3. 정보 구조
- **주제:** 시간이 지날수록 품격이 더해지는 수제 가죽 마패 키링
- **부주제:** 3D 이니셜 커스텀, B2B 기업 기프트, 장인 핸드크래프트
- **메뉴:** Customizer, Atelier Craft, B2B Bulk Order, Packaging
- **콘텐츠:** 3D 뷰어, 장인 영상, 가죽 룩북, 견적 신청 폼
- **정보 유형:** 사실 (가죽 종류, B2B 단가), 개념 (아틀리에 서사), 과정 (3D 커스텀), 절차 (견적 문의)

#### 4. 내비게이션
- **시작 화면:** 3D 가죽 키링 커스텀 시뮬레이터 메인 히어로
- **이동 경로:** 히어로 3D 커스텀 → 장인 공방 스토리 → B2B 기업 견적 폼 → 패키지 안내
- **연결 페이지:** [3D 커스텀 완성] → 주문/견적 신청 폼에 선택한 가죽/각인 옵션 자동 세팅
- **검색 및 위치 안내:** 상단 GNB 및 우하단 B2B 퀵 문의 바

#### 5. 화면 구성
- **헤더:** SADAN ATELIER 로고, GNB, 3D 커스텀 CTA
- **내비게이션:** 상단 고정 내비게이션 바
- **핵심 콘텐츠 (바디):** 3D 커스텀 시뮬레이터 UI, 장인 비디오, 가죽 에이징 룩북, B2B 견적 문의 폼
- **보조 콘텐츠 (어사이드):** 우하단 [B2B 대량 문의] 스티키 버튼
- **푸터:** 아틀리에 정보, 주문 제작 약관, AS 안내, SNS

#### 6. 검토 결과
- **누락 항목:** 없음
- **중복 항목:** 가죽 소재 설명을 3D 시뮬레이터 내부 옵션 설명으로 일원화
- **사용자 관점의 개선점:** 모바일에서 손가락 터치로 키링을 360도 회전할 수 있도록 3D UX 최적화
- **수정 사항:** 클래식 다크 브라운과 황동 골드 포인트 컬러 적용
