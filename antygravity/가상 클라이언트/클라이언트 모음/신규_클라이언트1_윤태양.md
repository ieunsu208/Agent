### 📌 9단계 가상 클라이언트 분석 프로세스

#### 1) 기본 정보 설정
- **프로젝트 주제:** K-헤리티지 암행어사 출두 체험 페스티벌 & 성수/경복궁 팝업 패스 '사단 페스티벌' 웹사이트 기획
- **제작 목적:** 사단 어사 출두 페스티벌 사전 얼리버드 티케팅 유치 및 웰컴 키트 수령 예약 모집
- **제공 자료:** 페스티벌 브리프, 공간 배치 지도, 웰컴 키트 사양서
- **필요 정보/기능:** 3D 어사 출두 모션 히어로, 타임테이블 & 부스 위치 지도, 얼리버드 패스 1-Click 예매, 웰컴 키트 구성 안내
- **작업 우선순위:** ① 얼리버드 패스 예매 → ② 타임테이블 & 시향 부스 지도 → ③ 웰컴 키트 소개 → ④ 페스티벌 스토리
- **적용 매체:** 모바일 퍼스트 반응형 웹

#### 4) 비슷한 항목끼리 분류
- **그룹 1 (페스티벌 비주얼):** 3D 어사 출두 모션, 페스티벌 메인 트레일러 영상
- **그룹 2 (행사 안내 & 지도):** 성수/경복궁 시향 부스 인터랙티브 지도, 시간대별 타임테이블
- **그룹 3 (티케팅 & 예약):** 얼리버드 패스 예매 모달, 카카오톡 알림톡 연동
- **그룹 4 (웰컴 키트 & 굿즈):** 웰컴 키트 구성품 갤러리, 현장 수령 절차 안내

#### 5) 계층 구조 작성 (Information Architecture)
```text
사단 어사 출두 페스티벌 웹사이트
├─ 1. Festival Intro (세계관)
│  ├─ 3D 어사 출두 인터랙티브 히어로
│  │  ├─ 메인 트레일러 영상 (Sound On/Off 토글)
│  │  └─ 3D 출두 모션 그래픽
│  └─ K-헤리티지 향 페스티벌 서사
│     ├─ 암행어사 비밀 첩보 세계관 스토리
│     └─ 힙트래디션 향 모듈 컨셉 비주얼
├─ 2. Timetable & Map (행사 안내)
│  ├─ 시향 부스 & 체험존 인터랙티브 지도
│  │  ├─ 성수 팝업존 & 경복궁 시향존 부스 핀
│  │  └─ 부스별 향 노트 상세 팝업 (1·2·3마패)
│  └─ 날짜/시간별 프로그램 타임테이블
│     ├─ DAY 1~3 일자별 일정 탭
│     └─ 조향사 클래스 & 아티스트 라이브 세션 시간표
├─ 3. Welcome Kit (웰컴 키트)
│  ├─ 페스티벌 한정 어사 마패 뱃지 & 키링
│  │  ├─ 한정판 금속 마패 뱃지 고화질 컷
│  │  └─ 수공예 패브릭 노리개 키링 굿즈 갤러리
│  └─ 현장 수령 장소 안내
│     ├─ 부스별 현장 수령처 약도
│     └─ 수령용 QR 코드 발급 절차
└─ 4. Pass Ticket (패스 예매)
   ├─ 얼리버드 패스 사전 예매 모달
   │  ├─ 1,000명 한정 방문 일자 & 수량 선택 (최대 4매)
   │  ├─ 예매자 정보 입력 (성함 / 연락처)
   │  └─ 예매 완료 및 카카오 알림톡 전송
   └─ 참가 기대평 & SNS 공유 이벤트
      ├─ 실시간 참가 기대평 작성 및 댓글 목록
      └─ 인스타그램 룩북 연동 그리드
```

#### 6) 사용자가 이해하기 쉬운 이름 부여 (레이블링)
- `Festival Intro`: 페스티벌 세계관과 압도적 모션 비주얼을 선보이는 레이블
- `Timetable & Map`: 시향 부스 위치와 프로그램 시간을 직관적으로 전달
- `Welcome Kit`: 현장 제공 사은품 혜택을 부각하는 메뉴
- `Pass Ticket`: 사전 패스 예매를 직관적으로 전달하는 핵심 레이블

#### 7) 내비게이션 연결
- **글로벌 내비게이션 (GNB):** 상단 고정 (로고, Intro, Timetable, Welcome Kit, [Pass 예매] 버튼)
- **이동 경로 & 연결:**
  - 히어로 [패스 예매하기] 클릭 → 예매 날짜/인원 선택 모달 연동 → 카카오톡 알림톡 발행
  - 지도 내 부스 핀 클릭 → 해당 공간 아로마 정보 팝업 오픈

### 📝 6대 필수 작성 양식

#### 1. 가상 클라이언트
- **프로젝트 주제:** 사단 어사 출두 K-헤리티지 향 페스티벌 & 팝업 패스 웹사이트 기획
- **제작 목적:** 페스티벌 사전 얼리버드 패스 티케팅 및 웰컴 키트 현장 수령 예약 모집
- **제공 자료:** 페스티벌 브리프, 시향 부스 지도, 웰컴 키트 사양서
- **적용 매체:** 모바일 퍼스트 반응형 웹

#### 2. 클라이언트 요구사항
- **요청 항목:** 3D 어사 출두 모션 히어로, 시향 부스 인터랙티브 지도, 얼리버드 패스 예매 모달, 웰컴 키트 안내
- **중요도:** 패스 예매 모달(높음), 부스 지도(높음), 웰컴 키트(보통)
- **관련 자료:** 신규 클라이언트 1 브리프
- **필요한 기능:** 3D 모션 비디오, 날짜선택 예매 모달, 부스 지도 UI, 실시간 잔여 티켓 카운터

#### 3. 정보 구조
- **주제:** K-헤리티지 향과 어사 출두 세계관이 결합된 오프라인 축제
- **부주제:** 시향 부스 맵, 얼리버드 티케팅, 웰컴 키트 굿즈
- **메뉴:** Festival Intro, Timetable & Map, Welcome Kit, Pass Ticket
- **콘텐츠:** 3D 비디오, 인터랙티브 지도, 탭 타임테이블, 예매 모달
- **정보 유형:** 개념 (세계관), 사실 (부스 위치, 굿즈 사양), 절차 (패스 예매)

#### 4. 내비게이션
- **시작 화면:** 3D 어사 출두 모션 히어로 세션
- **이동 경로:** 히어로 → 부스 지도 → 타임테이블 → 웰컴 키트 → 패스 예매 모달
- **연결 페이지:** [패스 예매] 클릭 → 날짜/인원 선택 모달 → 카카오톡 알림톡 전송
- **검색 및 위치 안내:** 상단 GNB, 모바일 하단 스티키 티케팅 바

#### 5. 화면 구성
- **헤더:** SADAN FESTIVAL 로고, GNB, 패스 예매 CTA
- **내비게이션:** 상단 고정 내비게이션 바
- **핵심 콘텐츠 (바디):** 3D 히어로, 부스 지도 UI, 타임테이블, 웰컴 키트 갤러리, 예매 모달
- **보조 콘텐츠 (어사이드):** 모바일 하단 스티키 잔여 티켓 카운트다운 바
- **푸터:** 페스티벌 주최사, 오시는 길, 약관, SNS

#### 6. 검토 결과
- **누락 항목:** 없음
- **중복 항목:** 행사 소개 텍스트 간소화 및 지도 UI 중심으로 통합
- **사용자 관점의 개선점:** 모바일에서 부스 위치를 터치하면 해당 부스 향 설명 팝업이 노출되도록 개선
- **수정 사항:** 페스티벌 느낌을 살린 네온 샌드 골드 포인트 컬러 적용
