#### 1) 기본 정보 설정
- **프로젝트 주제:** 조선 암행어사 마패 헤리티지 기반 커스텀 레이어링 퍼퓸 브랜드 '사단(士團)' 자사몰 메인페이지 기획
- **제작 목적:** 자사몰 론칭 안내, 마패 커스텀 퍼퓸 사전 예약 및 디스커버리 키트 신청자 모집
- **제공 자료:** 클라이언트 요청 브리프(`클라이언트1.txt`), 브랜드 정체성 문서(`브랜드_정체성.md`), FGI 및 타깃 인터뷰(`인터뷰.md`)

### 📝 6대 필수 작성 양식

#### 1. 가상 클라이언트
- **프로젝트 주제:** 사단(士團) 커스텀 레이어링 퍼퓸 브랜드 자사몰 메인페이지 기획
- **제작 목적:** 암행어사 마패 헤리티지 브랜드 론칭 알림, 커스텀 향 레이어링 체험 제공, 디스커버리 키트 사전 예약 유치
- **제공 자료:** 클라이언트 요구 브리프, 브랜드 정체성 문서, 타깃 인터뷰 및 FGI 데이터
- **적용 매체:** 웹 (반응형 PC / Mobile)

#### 2. 클라이언트 요구사항
- **요청 항목:** 1·2·3마패 라인업 구분, 온라인 커스텀 향 레이어링 시뮬레이터, 어사 첩보 디스커버리 키트 사전 신청, 비건 성분 및 제로 웨이스트 리필 가이드
- **중요도:** 디스커버리 키트 신청(높음), 레이어링 시뮬레이터(높음), 제품 라인업 구분(높음), 룩북 갤러리(보통)
- **관련 자료:** `브랜드_정체성.md`, `인터뷰.md`
- **필요한 기능:** 탭 전환형 상품 카드, 인터랙티브 믹싱 차트, 디스커버리 키트 1-Click 신청 폼, 모바일 스티키 플로팅 바

#### 3. 정보 구조
- **주제:** 조선 마패 헤리티지 기반 프리미엄 커스텀 퍼퓸 서비스
- **부주제:** 1·2·3마패 모듈 퍼퓸, 어사 비밀 첩보 레이어링 레시피, 디스커버리 체험 키트
- **메뉴:** About Sadan, Lineup, Custom Lab, Discovery, Sustainability
- **콘텐츠:** 브랜드 비디오, 제품 카드, 레이어링 시뮬레이터, 룩북 슬라이더, 화해 성분표, 신청 폼
- **정보 유형:** 사실 (제품 사양, 전성분), 개념 (세계관 스토리), 과정 (향 레이어링), 절차 (사전 신청)

#### 4. 내비게이션
- **시작 화면:** 마패 헤리티지 3D 비디오 히어로 세션
- **이동 경로:** 히어로 → 브랜드 스토리 → 제품 라인업 탭 → 향 레이어링 랩 → 룩북 갤러리 → 신청 폼
- **연결 페이지:** 커스텀 조합 결과 → 디스커버리 키트 신청 폼 자동 연동
- **검색 및 위치 안내:** 상단 GNB 고정, 브레드크럼 안내, 우하단 스티키 플로팅 바

#### 5. 화면 구성
- **헤더:** 브랜드 로고, GNB 메인 메뉴, 사전 예약 CTA 버튼
- **내비게이션:** 상단 글로벌 내비게이션 바 및 라인업 로컬 탭
- **핵심 콘텐츠 (바디):** 브랜드 히어로 비디오, 1·2·3마패 탭 카드, 커스텀 레이어링 시뮬레이터, 스타일링 갤러리, 디스커버리 키트 신청 영역
- **보조 콘텐츠 (어사이드):** 우하단 스티키 플로팅 버튼 (사전 예약 팝업 연동)
- **푸터:** 사단 법인 정보, 서비스 이용약관, 개인정보처리방침, 공식 SNS 링크

#### 6. 검토 결과
- **누락 항목:** 없음 (사전 예약 단계이므로 본품 결제 모듈 제외 요구 준수)
- **중복 항목:** 1마패 스틱 및 2마패 액상 설명 중복 최소화, 용도별 탭 분리로 명확화
- **사용자 관점의 개선점:** 모바일 환경에서 마패 그립감 및 키링 착용 컷의 선명도 강화 필요
- **수정 사항:** 텍스트 위주 향 설명 대신 노트별 발향 그래프 차트로 시각화 전환
