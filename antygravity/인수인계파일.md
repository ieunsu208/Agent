## 3. 핵심 데이터 관리 & 결과물 생성 규칙

1. **기본 자료 자동 감지**:
   - 파일명에 `[리서치 결과]`가 포함된 모든 `.txt` 파일을 기본 리서치 자료로 자동 탐색하여 사용.
2. **추가 자료 동적 인식**:
   - 사용자가 `"리서치 자료 추가 입력"`이라고 명령하면 이후 입력되는 파일, URL, 텍스트를 추가 자료로 인식.
3. **누적 병합 (Non-destructive)**:
   - 추가 자료는 기존 자료를 덮어쓰지 않고 항상 누적하여 저장.
4. **출처 구분 명시 (Provenance)**:
   - 분석 결과물에서 해당 내용이 `[기본자료]` 출처인지 `[추가자료]` 출처인지 구분하여 기록.
5. **중복 통합 및 출처 보존 (Deduplication)**:
   - 동일 브랜드/홈페이지가 중복 등장할 경우 1개 항목으로 합치되 발견된 모든 출처 기록.
6. **100개 단위 원자적 분할 저장 규칙**:
   - 모든 결과물은 UTF-8 인코딩 `.txt` 파일 형태로 `output/` 폴더 내 생성.
   - 메모장 1개당 최대 100개 홈페이지 수록 (100개 초과 시 `001-100`, `101-200` 분할 파일명 사용).
   - **원자성 보장**: 한 홈페이지의 분석 내용이 절대로 두 파일 간에 나눠서 저장되지 않음.
7. **3종 파일 영역 분리**:
   - `output/01_개별분석_001-100.txt` (개별 홈페이지 상세 분석 시리즈)
   - `output/02_전체비교분석.txt` (패턴, 등장 비율, 공통점/차이점, 장단점 분석)
   - `output/03_최종인사이트.txt` (적용 아이디어, 우선 참고 레퍼런스, 주의점, 추가 조사 항목)
