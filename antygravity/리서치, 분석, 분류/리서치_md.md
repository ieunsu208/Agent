## 1. 브랜드 컨텍스트 (Brand Identity)

* **브랜드명:** 사단 (士團 / Sadan)
* **브랜드 정의:** 조선 암행어사의 마패 헤리티지를 현대적으로 재해석한 커스텀 레이어링 향수 브랜드
* **핵심 가치:** 유일성, 실용성, 스토리텔링
* **디자인 무드:** 오리엔탈 모던 (Oriental Modern). 한지, 스톤, 자연적 질감과 견고하고 맑은 투명 용기의 시각적 대비. 정갈하고 차분한 미니멀 룩앤필.

## 2. 필수 산업군 배분 비율 (Cross-Industry Quotas) - 핵심 강제 규칙

목표 수집 사이트 중 **특정 카테고리 쏠림을 방지하기 위한 강제 비율 제한**을 적용한다:

1. **향수/뷰티/코스메틱 카테고리:** **최대 20% 이내 제한 (절대 상한선)**
   - 이솝, 르 라보, 바이레도 스타일의 유사 향수 D2C 사이트의 과도한 수집을 철저히 배제한다.
2. **타 산업군 Cross-Benchmarking:** **최소 80% 이상 필수 포함**
   - **전통 차(Tea) & 음료 블렌딩 (20%):** 차 레이어링/조합 인터랙티브 가이드 UX
   - **하이엔드 시계/커스텀 주얼리 (20%):** 실시간 이니셜 각인 및 커스텀 3D/2D 컨피규레이터
   - **전통 공예/주류/아카이브 박물관 (20%):** 헤리티지 도록 갤러리 및 서사 해금 UX
   - **에디토리얼 패션/아키텍처/디자인 스튜디오 (20%):** 파격적인 Grid, Split-Screen, 가로 스크롤 레이아웃

## 3. 8대 UX 레이아웃 아키타입 (Layout Archetypes) 강제 조건

모든 수집 사이트는 아래 8가지 아키타입 중 하나로 명확히 분류되어야 하며, **단일 아키타입 비율이 전체의 25%를 초과할 수 없다.**

1. **Split-Screen Canvas:** 화면이 50:50으로 고정 분할되어 한쪽은 브랜딩 비주얼, 한쪽은 스크롤 탐색을 제공하는 구조
2. **Horizontal Scroll Timeline:** 좌우 가로 스크롤을 통해 헤리티지 타임라인이나 룩북을 전개하는 구조
3. **Interactive Configurator / Builder:** 사용자가 옵션(향/이니셜)을 클릭할 때마다 캔버스상의 오브제 연출이 실시간 변경되는 조립 구조
4. **Chapter-based Editorial Magazine:** 잡지 목차 형태의 슬라이드나 챕터 선택을 통해 정보를 해금하는 구조
5. **Interactive Accordion Matrix:** 복잡한 정보(원료, 성분, 스토리)를 여백 중심의 아코디언 매트릭스로 정갈하게 펼치는 구조
6. **Full-Bleed Object Showcase:** 1열 풀스크린 고해상도 오브제 질감 포커스 구조
7. **Filter-Driven Dynamic Grid:** 다차원 필터링 기반의 가변형 갤러리 구조
8. **Minimalist Step-by-Step Flow:** 1단계부터 N단계까지 질의응답 형태로 맞춤 제품을 찾아가는 단계별 구조

## 4. 엄격한 중복 및 유사성 필터링 (Validation & Anti-Similarity)

다음 조건 중 하나라도 해당할 경우 즉시 수집 대상에서 제외한다:

### 4-1. URL 및 브랜드 중복
* 동일 루트 도메인, 글로벌/국가별 서브도메인, 하위 서브페이지 중복 엄금.

### 4-2. UX 프론트엔드 기능 조합 중복 (Anti-Feature Co-occurrence)
* `2열 Grid + Slide-over Drawer Cart + 향 노트 아코디언` 기능 조합은 **전체 리서치 항목 중 최대 2개(10%)까지만 허용**.
* 기능 구성 및 사용자 탐색 동선이 70% 이상 일치하는 사이트는 도메인이 달라도 중복으로 처리하여 삭제.

### 4-3. 배제 대상 디자인 (Negative Constraints)
* 이솝(Aesop) 템플릿 복제형 사이트
* 과도한 WebGL 3D 연출로 인한 로딩 지연 사이트
* 접속 불가(HTTP status != 200) 및 Dead link 사이트

## 7. 최종 Duplicate & Similarity Audit (필수 점검)

파일 작성 완료 전 아래 항목을 100% 검증한다:
- [ ] 향수/뷰티 비율이 20% 이내인가?
- [ ] 8대 UX 레이아웃 아키타입이 골고루 분산되었는가?
- [ ] 동일한 UI 기능 조합(2열 그리드 + Slide Cart 등)이 반복되지 않았는가?
- [ ] HTTP 200 정상 렌더링 사이트인가?
