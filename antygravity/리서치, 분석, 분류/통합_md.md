# 사단(Sadan) 웹사이트 기획 통합 파이프라인 지시서 (통합_md.md)

본 지시서는 사단 브랜드 웹사이트 기획 및 와이어프레임 설계를 위해 **[1단계: 리서치 수집] ➔ [2단계: 데이터 분류] ➔ [3단계: 데이터 분석] ➔ [4단계: 사내 의사결정 보고]**로 이어지는 에이전트 통합 워크플로우를 진행하며, 분석 보고서와 최종 의사결정 결과 보고서가 혼동되지 않도록 각각 **독립된 개별 파일로 분리하여 전용 결과 폴더(`결과/`) 내에 생성 및 저장**하도록 규정합니다.

---

## 0. 공통 브랜드 컨텍스트 (Brand Identity)

에이전트는 전체 파이프라인 실행 시 다음 브랜드 컨텍스트를 모든 기준의 최우선으로 적용합니다.
* **브랜드명:** 사단 (士團 / Sadan)
* **브랜드 정의:** 조선 암행어사의 마패 헤리티지를 현대적으로 재해석한 커스텀 레이어링 향수 브랜드
* **핵심 가치:** 유일성, 실용성, 스토리텔링
* **디자인 무드:** 오리엔탈 모던 (Oriental Modern). 한지, 스톤, 자연적 질감과 견고하고 맑은 투명 용기의 시각적 대비. 정갈하고 차분한 미니멀 룩앤필.

## 0-1. 전용 결과 폴더(`결과/`) 및 4대 독립 개별 파일 명세 (Dedicated Output Rules)

분석 보고서와 최종 결과 보고서의 혼선을 완전히 제거하기 위해 통합 합본 파일(`사단_웹사이트_기획_통합_최종보고서.md`)을 폐지하고, **각 단계의 역할에 맞는 4개의 독립된 개별 파일**을 전용 결과 폴더인 `결과/` 내부에 생성합니다.

```text
[입력/읽기 경로]                      [전용 결과 폴더 (결과/) 내 4대 독립 파일]              [버려진/백업 파일 경로]
master_references.txt         ──►  결과/new_references.txt (1단계 수집 결과)           ──►  archive/rejected_references.txt (탈락 사이트)
[리서치 결과]*.txt             ──►  결과/classification-result.md (2단계 분류 결과)      ──►  archive/history_타임스탬프.md
                              ──►  결과/analysis-report.md (3단계 순수 분석 보고서)
                              ──►  결과/executive-report.md (4단계 사내 최고결정권자 보고서)
```

### 1. 읽을 파일 위치 (Input File Locations)
* **1단계 수집 읽기:** `master_references.txt`, `[리서치 결과]*.txt` (기존 수집 데이터 및 워크스페이스 내 기본 리서치 자료)
* **2단계 분류 읽기:** 1단계에서 수집되어 `결과/new_references.txt`에 저장된 데이터
* **3단계 분석 읽기:** 2단계에서 구조화 맵핑되어 `결과/classification-result.md`에 저장된 데이터
* **4단계 최종 보고 읽기:** 3단계 데이터 분석 결과(`결과/analysis-report.md`)

### 2. 전용 결과 폴더 내 4대 독립 개별 파일 명세 (Dedicated Output Files - 핵심)
파이프라인 실행 시 **`결과/` 폴더 내에 4개의 독립된 파일**을 각각 새로 생성합니다:
1. **`결과/new_references.txt`**: 1팀(리서치 팀)의 80:20 비율 준수 및 검증 완료된 레퍼런스 수집 리스트
2. **`결과/classification-result.md`**: 2팀(분류 팀)의 UX/IA 구조 및 시각적 무드 매핑 종합 분류표
3. **`결과/analysis-report.md`**: 3팀(분석 팀)의 순수 데이터 분포, UX 패턴 및 상관관계 분석 보고서 *(분석 전용)*
4. **`결과/executive-report.md`**: 총괄 부장 및 사장(대표) 제출용 **[팀원 ➔ 팀장 ➔ 부장 ➔ 사장]** 4단계 사내 의사결정 결과 보고서 *(최종 의사결정 전용)*

### 3. 버려진 파일 / 탈락 레퍼런스 저장 위치 (Discarded & Rejected File Locations)
* **검증 탈락/버려진 레퍼런스 저장:** `archive/rejected_references.txt`
  - **저장 대상:** 중복 도메인/브랜드, Dead Link (HTTP status != 200), UX 패턴 중복(70% 이상), 배제 대상 디자인(과도한 3D, 이솝 복제형) 사이트 정보 및 **탈락 사유** 기록

## 0-2. 전문 팀별 역할 및 파이프라인 매핑 명세 (Team Responsibility Mapping)

`조직구조.md`에 규정된 3개 전문 팀이 파이프라인 각 단계를 독립적으로 담당하여 실행합니다:

1. **[1단계: 리서치 수집] ➔ 담당: 1팀 - 리서치 팀 (Research Team)**
   - **관련 파일/스킬:** `리서치_md.md`, `리서치_skill.md`
   - **핵심 역할:** 8대 UX 아키타입 수집 및 타 산업군 80% cross-benchmarking 수집 (`결과/new_references.txt`)
2. **[2단계: 데이터 분류] ➔ 담당: 2팀 - 분류 팀 (Classification Team)**
   - **관련 파일/스킬:** `분류_md.md`, `분류_ skill.md`
   - **핵심 역할:** 수집 데이터의 UX/IA 구조(주 분류) 및 시각적 무드(부 분류) 맵핑 (`결과/classification-result.md`)
3. **[3단계: 데이터 분석] ➔ 담당: 3팀 - 분석 팀 (Analysis Team)**
   - **관련 파일/스킬:** `분석_md.md`, `분석_skill.md`
   - **핵심 역할:** 분류 데이터 분석, 사단 브랜드 핏 검증 및 순수 패턴 분석 보고서 작성 (`결과/analysis-report.md`)
4. **[4단계: 사내 의사결정 보고] ➔ 담당: 총괄 부장 ➔ 사장(최고결정권자)**
   - **핵심 역할:** 부장의 2개 전략안 압축 필터링 및 사장 최고결정권자 최종 승인 결과 보고서 독립 작성 (`결과/executive-report.md`)

# [PART 3] 3단계: 순수 레퍼런스 데이터 분석 (3팀 - 분석 팀)

이 단계의 목표는 분류된 데이터를 객관적으로 분석하여 패턴과 상관관계를 도출하는 것이다.

* **읽을 파일 위치:** `결과/classification-result.md`
* **저장 파일 위치:** `결과/analysis-report.md`
* **필수 작성 규칙 (숫자만 표기 금지):**
  - **카테고리 및 UX 구조 분포 요약 시 단순 수치(예: 4개, 20%)만 적는 것을 엄격히 금지한다.**
  - 해당 수치에 해당되는 **모든 실제 브랜드명과 마크다운 URL 링크 리스트([브랜드명](URL))**를 구체적으로 반드시 명시한다.

# [PART 4] 4단계: 사내 의사결정 결과 보고 (총괄 부장 ➔ 사장)

이 단계의 목표는 분석 결과를 사내 의사결정 체계에 맞춰 사장(최고결정권자)에게 보고하고 와이어프레임 설계 지침(Actionable Insights)을 도출하는 것이다.

* **읽을 파일 위치:** `결과/analysis-report.md`
* **저장 파일 위치:** `결과/executive-report.md`
* **필수 작성 규칙 (장점만 적기 금지, 안별 3대 추천 벤치마킹 사이트 포함):**
  - 단순 안별 장점만 나열하는 보고서를 금지한다.
  - **[제 1안]** 및 **[제 2안]** 각각에 대해 사단 브랜드 기획 시 **직접 벤치마킹할 대표 추천 웹사이트 3곳**을 반드시 선정하고 아래 포맷으로 작성한다:
    1. **[브랜드명](URL)**: 참고할 핵심 UI/UX 요소 및 사단 브랜드 핏 적용 사유 명시
* **사내 의사결정 보고 체계 (독립 작성):**
  1. **[1단계: 팀원 아이디어 및 데이터 수집 (Team Level Input)]** (리서치/분류/분석 팀)
  2. **[2단계: 팀장 1차 의사결정 및 팀 최종안 선별 (Team Leader Primary Choice)]**
  3. **[3단계: 총괄 부장 검토 및 2개 안 압축 (General Manager Filtering)]**
  4. **[4단계: 사장(대표) 최종 보고 및 결론 (CEO Final Report & Actionable Insights)]** (안별 대표 추천 3대 벤치마킹 사이트 포함)
