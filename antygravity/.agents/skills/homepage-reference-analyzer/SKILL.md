# Homepage Reference Analyzer Skill

이 스킬은 웹사이트/홈페이지 UI/UX 레퍼런스 자료를 수집, 분류 및 종합 분석하여 100개 단위 원자적 분할 규칙을 준수하는 UTF-8 .txt 보고서를 자동 생성합니다.

---

## 1. 분석 대상 및 범위 (Scope)
다음 5가지 핵심 영역을 중심으로 레퍼런스를 분류하고 분석합니다:
1. **디자인 스타일**: 룩앤필, 타이포그래피, 여백, 비주얼 텍스처, 브랜드 무드
2. **화면 구성 및 레이아웃**: CSS Grid, 2열 카드, 에디토리얼 레이아웃, 스티키 스크롤 등
3. **메뉴 및 사용자 흐름 (Navigation & Flow)**: 뎁스 간소화, Drawer 메뉴, 결제/탐색 동선
4. **문구 및 콘텐츠 (Copywriting)**: 스토리텔링, 텍스트 아카이브, 헤리티지 연출
5. **주요 기능 (Features & Interactions)**: 커스텀 빌더, Quick Add Cart, 필터링, 아코디언 컴포넌트

---

## 2. 자료 수집 및 데이터 관리 규칙 (Input Rules)
1. **기본 자료 자동 감지**:
   - 워크스페이스 내 파일명에 `[리서치 결과]`라는 이름이 들어간 모든 `.txt` 파일을 기본 리서치 자료로 자동 인식하여 수집합니다.
2. **추가 자료 동적 인식 트리거**:
   - 사용자가 `"리서치 자료 추가 입력"`이라고 명령하면, 이후 제공되는 파일, URL, 텍스트를 추가 자료로 인식하여 수집합니다.
3. **누적 저장 (Non-destructive)**:
   - 새로 추가된 자료는 기존 분석 데이터를 덮어쓰지 않고 항상 누적하여 관리합니다.
4. **출처 명시 (Provenance)**:
   - 모든 분석 결과에서 해당 항목이 `[기본자료]` 출처인지 `[추가자료]` 출처인지 명확히 표시합니다.
5. **중복 통합 및 출처 보존 (Deduplication)**:
   - 동일한 홈페이지/브랜드가 중복 등장할 경우 하나의 항목으로 통합하되, 발견된 모든 출처(파일명, URL 등)를 남깁니다.
6. **통합 분석**:
   - 기본 자료와 추가 자료를 함께 사용하여 수치 집계 및 인사이트를 도출합니다.

---

## 3. 분석 결과 파일 생성 및 분할 규칙 (Output File Rules)
1. **UTF-8 인코딩**: 모든 결과물은 UTF-8 인코딩 형태의 `.txt` 파일로 출력합니다.
2. **수량 제한**: `.txt` 파일 1개당 최대 **100개**의 홈페이지 분석 항목을 수록합니다.
3. **분할 네이밍 규칙**: 100개 초과 시 `001-100`, `101-200` 형태로 분할 명칭을 부여합니다.
4. **카운팅 단위**: 홈페이지 하나를 분석 결과 1개 수량 단위로 계산합니다.
5. **파일 영역 분리**: 아래 3가지 분석 영역을 완전히 별도의 `.txt` 파일로 생성합니다:
   - **개별 분석 파일 시리즈**: `01_개별분석_001-100.txt`, `01_개별분석_101-200.txt` 등
   - **전체 비교 분석 파일**: `02_전체비교분석.txt`
   - **최종 인사이트 파일**: `03_최종인사이트.txt`
6. **원자성 보장 (분할 금지)**: 한 홈페이지의 분석 내용은 절대로 두 파일로 나뉘어 저장되지 않으며, 100번째 항목 완료 후 101번째 항목부터 다음 파일에서 온전히 시작합니다.

---

## 4. 8단계 분석 프로세스 (Core Analysis Workflow)

### 1단계: 홈페이지별 개별 분석
- 각 홈페이지의 기본 정보(이름, URL, 업종) 및 7대 항목(디자인 특징, 화면 구성, 사용자 흐름, 문구와 콘텐츠, 주요 기능, 장점과 단점, 참고할 부분)을 추출합니다. *(추후 4단계/5단계 세부 지침 반영 가능)*

### 2단계: 비슷한 내용 묶기
- 여러 홈페이지에서 공통/유사하게 나타나는 UI/UX 요소 및 디자인 스타일을 하나의 그룹으로 묶습니다.

### 3단계: 등장 횟수 및 비율 집계
- 각 그룹별로 몇 개의 홈페이지에서 등장했는지 개수와 전체 대비 비율(%)을 명시합니다.

### 4단계: 수치 기반 패턴 구분
- **공통 패턴**: 전체 레퍼런스 중 30% 이상 등장
- **반복 패턴**: 10% 이상 30% 미만 등장
- **특이 사례**: 10% 미만이지만 아이디어가 우수한 경우 별도 발굴 기록

### 5단계: 공통점과 차이점 분석
- 대부분 사용하는 방식, 업종별 차이 방식, 반대 방식, 단독 브랜드 특징 방식으로 구분 정리합니다.

### 6단계: 장점과 문제점 분석
- 각 패턴별로 패턴명, 사용 홈페이지, 장점, 단점, 어울리는 상황, 주의할 점을 서술합니다.

### 7단계: 최종 인사이트 도출
- **반드시 참고할 공통 방식**, **상황별 선택 방식**, **차별화 독특 방식** 3가지로 정리하고 관련 레퍼런스 출처를 링크/연결합니다.

### 8단계: 추가 조사 항목 표시
- 자료만으로 판단하기 어려운 항목은 추측하지 않고 `추가 조사 필요 / 확인할 내용 / 현재 부족한 근거`로 분명히 기재합니다.
