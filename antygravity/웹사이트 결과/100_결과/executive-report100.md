### ◈ [제 1안] 미래 성장 동력 발굴 (1팀 리서치 팀 제안 / 창의적 접근)
* **주요 내용:** '포터블 마패 메탈 용기 실시간 3D 각인 시뮬레이터 + 50:50 Split 비주얼 캔버스'
* **기대 효과:** 사용자 맞춤 이니셜 각인 경험을 통해 독점적인 오리엔탈 럭셔리 브랜딩 가치 창출.

#### 📌 제1안 참고할 3대 벤치마킹 웹사이트
1. **[메종 루이 마리](https://maisonlouismarie.com)**
   - **참고 요소:** Filter-Driven Dynamic Grid / CSS Grid 비주얼 카드 레이아웃, 향 노트 아코디언 컴포넌트, Quick Add 카트 Drawer
   - **사단 핏:** 정갈한 여백과 에디토리얼 타이포그래피가 사단의 오리엔탈 모던 무드와 부합함.
2. **[이솝](https://www.aesop.com)**
   - **참고 요소:** Full-Bleed Object Showcase / 미니멀 Sticky 스크롤, 모듈형 탭 가이드, 스톤/용기 시각적 대비 쇼케이스
   - **사단 핏:** 자연 질감 배경과 견고한 투명 용기의 미니멀 오리엔탈 룩앤필을 구현함.
3. **[르 라보](https://www.lelabofragrances.com)**
   - **참고 요소:** Interactive Configurator / Builder / 타자기 에디토리얼 그리드, 커스텀 라벨링 실시간 텍스트 프리뷰어
   - **사단 핏:** 100% 커스텀 레이어링 및 어사 마패 이니셜 각인 프리뷰 모듈에 적합함.

### ◈ [제 2안] 내실 강화 및 수익 극대화 (3팀 분석 팀 제안 / 직관적 접근)
* **주요 내용:** '2열 카드 필터 그리드 + 향 노트 드롭다운 + Slide Cart Drawer'
* **기대 효과:** 탐색 뎁스를 2단 이하로 낮춰 단기 매출 전환율(ROI) 및 이커머스 실용성을 최극대화.

#### 📌 제2안 참고할 3대 벤치마킹 웹사이트
1. **[논픽션](https://nonfiction.com)**
   - **참고 요소:** Filter-Driven Dynamic Grid / 정갈한 2열 Grid 갤러리, 향 노트 드롭다운 필터, Slide-over 카트 Drawer
   - **사단 핏:** 정갈하고 차분한 모던 오리엔탈 감성의 이커머스 뼈대로 호환됨.
2. **[탬버린즈](https://www.tamburins.com)**
   - **참고 요소:** Full-Bleed Object Showcase / HD 3D 오브제 줌 비주얼 쇼케이스, 모듈형 옵션 Selector, Sticky GNB
   - **사단 핏:** 향수 용기를 오브제 아트워크처럼 극적으로 연출하는 히어로 섹션으로 활용됨.
3. **[바이레도](https://www.byredo.com)**
   - **참고 요소:** Chapter-based Editorial Magazine / 대담한 흑백 에디토리얼 타이포그래피, 가로 반응형 칼럼 그리드, 퀵 바잉 모달
   - **사단 핏:** 극도로 정제된 미니멀 디자인 룩앤필과 명확한 분류 구조를 지님.

## 2. 와이어프레임 설계 시사점 (Actionable Insights)

1. **마패 용기 이니셜 실시간 각인 3D 모듈 (1팀 리서치 팀 제안):**
   - 사용자가 문구를 입력하면 3D 마패 용기 표면에 실시간 각인되는 프리뷰어 배치.
2. **50:50 Split 화면 & 오리엔탈 에디토리얼 타이포 (2팀 분류 팀 제안):**
   - 스톤/한지 질감 비주얼과 넓은 여백 타이포 대치 구조.
3. **2단계 저마찰 Quick Cart Drawer (3팀 분석 팀 제안):**
   - 우측 슬라이드 결제 Drawer를 적용하여 구매 전환율(ROI) 극대화.
