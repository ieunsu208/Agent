# 가상 클라이언트 생성 및 작성 스킬 (클라이언트_생성_skill.md)

---

## 0. 개요 및 생성 원칙
* **스킬 목적:** 신규 클라이언트를 생성하거나 클라이언트 문서를 작성할 때 `가상 클라이언트 기반 분석 결과 작성 양식.md`에 기반하여 표준 9단계 분석 프로세스 및 6대 작성 양식 구조로 자동 생성한다.
* **재사용 금지 원칙:** 한 번 생성되거나 사용된 클라이언트는 다시는 사용하지 않으며, 신규 요청 시 반드시 겹치지 않는 새로운 가상 클라이언트를 생성한다.
* **기준 파일:** `가상 클라이언트/가상 클라이언트 기반 분석 결과 작성 양식.md`

---

## 1. 클라이언트 생성 9단계 프로세스

1. **기본 정보 설정:** 프로젝트 주제, 제작 목적, 클라이언트 제공 자료, 적용 매체(웹/모바일 등) 설정.
2. **요청 항목 수집:** 클라이언트의 요구사항을 항목별로 분해하고 관련 자료 및 중요도(높음·보통·낮음) 할당.
3. **정보 단위 변환:** 정보 유형(사실, 개념, 절차, 과정)과 정보 단계(주제→부주제→메뉴→콘텐츠), 화면/이동 요소 정의.
4. **항목 분류 및 그룹화:** 목적별 그룹 생성, 중복 제거 및 자료 유형 구분.
5. **계층 구조 작성 (IA):** 상위 메뉴에서 하위 콘텐츠로 연결 (한 단계 메뉴 폭 5~9개, 깊이 5단계 이내).
6. **레이블링:** 직관적이고 일관성 있는 명칭 부여.
7. **내비게이션 연결:** GNB, LNB, 브레드크럼, 검색 및 이동 경로 설계.
8. **와이어프레임 화면 구성:** 헤더, 내비게이션, 핵심 콘텐츠(바디), 보조 콘텐츠(어사이드), 푸터 영역 요소 정의.
9. **반복 검토:** 대조 체크리스트를 통한 최종 품질 검증.

---

## 2. 필수 클라이언트 작성 양식 구조

클라이언트 생성 결과물은 반드시 아래 6대 표준 항목을 포함하여 작성한다.

```markdown
# [클라이언트명 / 브랜드명] 가상 클라이언트 분석 보고서

## [ 9단계 가상 클라이언트 분석 프로세스 ]
(1단계 기본정보 ~ 9단계 검토 결과 상세)

## [ 최종 작성 양식 ]

### 1. 가상 클라이언트
- 프로젝트 주제:
- 제작 목적:
- 제공 자료:
- 적용 매체:

### 2. 클라이언트 요구사항
- 요청 항목:
- 중요도:
- 관련 자료:
- 필요한 기능:

### 3. 정보 구조
- 주제:
- 부주제:
- 메뉴:
- 콘텐츠:
- 정보 유형: (사실 · 개념 · 절차 · 과정)

### 4. 내비게이션
- 시작 화면:
- 이동 경로:
- 연결 페이지:
- 검색 및 위치 안내:

### 5. 화면 구성
- 헤더:
- 내비게이션:
- 핵심 콘텐츠:
- 보조 콘텐츠:
- 푸터:

### 6. 검토 결과
- 누락 항목:
- 중복 항목:
- 사용자 관점의 개선점:
- 수정 사항:
```

## 3. 검증 규칙

- [ ] 9단계 프로세스(요구사항 분석~와이어프레임 구조화)가 반영되어 있는가?
- [ ] 정보 유형(사실/개념/절차/과정) 및 계층 깊이 기준이 준수되었는가?
- [ ] 기존에 생성된 클라이언트 프로필(이름, 브랜드, 요구사항)을 재사용하지 않고 완전히 새로운 클라이언트로 생성했는가?
