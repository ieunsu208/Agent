# 밀도 브랜딩 프로세스: 레이아웃과 콘텐츠 기준

## 공통 기준

- 와이어프레임은 `브랜딩-프로세스-와이어프레임.html` **한 파일**에 섹션 순서대로 추가한다.
- 한 페이지의 기본 크기는 **1920 × 950px**이다. 너비는 유지하고 높이는 내용에 맞춰 조절한다.
- 좌우 여백 **120px**, **12열**, 열 간격 **24px**을 정렬 기준으로 쓴다. 전체 화면 이미지는 캔버스 끝까지 채우되 글과 주요 피사체는 그리드에 맞춘다.
- 한 페이지가 과도하게 길어지거나 내용이 서로 다른 두 핵심 단위로 나뉘면, 같은 섹션을 `04-리서치-01`·`04-리서치-02`처럼 두 페이지로 나눈다. 여백을 채우기 위해 내용을 늘리지 않는다.
- 와이어프레임은 흑백, 이미지 자리는 회색 박스로만 표현한다. 색상·사진 스타일·서체 선택은 디자인 단계에서 한다.
- 원본 레퍼런스와 TXT는 수정하지 않는다. 아래의 **추천**은 사용자 TXT에 없는 추가 의견이며, 확정 내용으로 간주하지 않는다.

내용이 많은 04·07·09·10은 분석 결과에 따라 같은 섹션을 두 페이지로 나눌 수 있다. 페이지 수는 레이아웃을 보기 전까지 확정하지 않는다.

## 01 썸네일 결정

- 한 장의 이미지가 1920 × 950px 전체를 채운다.
- 상품 피사체는 오른쪽 8~12열, 브랜드명과 한 줄 설명은 왼쪽 1~4열에 둔다.
- 그리드 선과 상품 위치 점선은 와이어프레임의 확인용 표시다.

## 02 오버뷰 레퍼런스 분석

이 섹션의 과제는 `오버뷰.txt`에 적힌 **브랜드 소개와 핵심 키워드 3개**다. 브랜드 소개 자료에는 조선 마패의 재해석, 시간에 따른 향의 레이어링, 가방과 몸에 지니는 향수 오브제가 반복해서 등장한다. 오버뷰에서는 이를 한 장에 압축하고, 07 컨셉과 09 향 시스템에서 다룰 상세 설명은 넘기지 않는다.

| 파일 | 관찰한 레이아웃 원리 | 밀도에 적용하는 방식 |
| --- | --- | --- |
| 2-1 | 배경 사진을 화면 전체에 깔고, 로고의 큰 덩어리와 설명의 작은 덩어리로 무게를 나눈다. | **시각적 무게 차이**만 참고한다. 전체 사진과 로고 배치는 오버뷰의 세 키워드를 읽기 어렵게 하므로 옮기지 않는다. |
| 2-2 | 텍스트가 차지하는 왼쪽은 비우고, 오른쪽의 오브제를 화면 가장자리까지 크게 크롭한다. | 오른쪽에 **큰 단일 피사체**를 두되 밀도에서는 정적인 진열 컷 대신 가방에 걸린 마패 향수의 사용 장면을 지정한다. 사진은 원형 창 안에 제한해 썸네일의 전체 화면 이미지와 구분한다. |
| 2-3 | 상단에서 브랜드 소개와 세 개념을 분리해 읽히게 하고, 사진은 그 아래에 별도 층으로 놓는다. | **소개 → 세 개념**이라는 정보 위계를 가져온다. 세 개념을 원 도식에 넣거나 하단 전체 사진을 그대로 복제하지 않고, 얇은 선으로 구분한 세 줄에 담는다. |
| 2-4 | 이미지의 크기를 키우고 가장자리에서 잘라 소재의 질감과 실루엣을 강조한다. | **크롭의 역할**을 참고한다. 과일 이미지와 중앙 정렬 글 배치는 밀도의 마패·휴대 경험과 맞지 않아 사용하지 않는다. |
| 2-5 | 좌우에 서로 다른 크기의 이미지를 걸치고 넓은 흰 여백에 문장을 띄운다. | **비대칭과 화면 밖으로 이어지는 크롭**을 원형 이미지에 적용한다. 중앙의 초대형 선언문은 레퍼런스처럼 커 보이므로 제외한다. |
| 2-6 | 상단의 간결한 소개 뒤에 세 장의 이미지가 같은 폭으로 이어져 개념을 보여준다. | 키워드가 **같은 비중으로 읽혀야 한다**는 점만 참고한다. 사진 세 장을 키워드마다 배정하면 한 브랜드의 경험이 조각나므로 사용하지 않는다. |
| 2-7 | 작은 소개문, 얇은 원 윤곽, 넉넉한 여백으로 부드러운 인상을 만든다. | 사용자가 선호한 **둥근 형태와 가벼운 선**을 채택한다. 원 세 개의 크기·위치·겹침·중앙 정렬 문구를 그대로 따르지 않고, 밀도의 마패 오브제를 위한 **원형 이미지 하나**로 변환한다. |

### 선택한 레이아웃과 이유

- **왼쪽 상단:** 12px 섹션명, 28px·보통 굵기 한 줄 제목, 14px 브랜드 소개로 시작한다. 2-7의 작은 글자와 여백 비율을 참고하되, 카피를 한 화면의 주인공으로 키우지 않는다.
- **왼쪽 하단:** 세 키워드를 번호·이름·설명의 세 열로 나누고, 얇은 가로선으로만 구분한다. 이름은 20px·보통 굵기, 설명은 13px이다. 2-3의 소개와 개념 위계, 2-6의 세 개념 동등성을 반영한다.
- **오른쪽:** 지름 835px의 둥근 이미지 영역 하나를 두고 오른쪽과 아래쪽 화면 밖으로 조금 확장한다. 2-7의 곡선감, 2-2의 오브제 크기, 2-4·2-5의 과감한 크롭을 조합한 자리다. 사진을 제작할 때는 마패 형태 향수가 가방에 걸린 모습이 크게 보여야 한다. 회색은 이미지 자리 표시이며 완성 사진이 아니다.
- **독자적인 결정:** 세 키워드를 원 세 개에 각각 넣지 않았다. **하나의 둥근 오브제와 세 줄의 브랜드 원리**라는 구성이 밀도의 제품 형태와 `오버뷰.txt`의 두 항목을 동시에 설명한다. 원을 쓰는 이유가 장식이 아니라 마패 오브제의 형태와 연결된다.
- **읽는 순서:** 브랜드 소개 → 세 키워드 → 사용 장면. 첫 장인 썸네일은 제품 단독 이미지이고, 오버뷰 이미지는 제품을 지니는 맥락을 보여준다.
- **문구 상태:** 위 문구는 브랜드 소개 자료를 압축한 시안이다. 사용자가 확정한 슬로건이나 최종 키워드로 취급하지 않는다.

## 03 백그라운드 레퍼런스 분석

`백그라운드.txt`에는 **기획하게 된 배경**만 적혀 있다. 사용자 제공 시장 조사 원문은 밀도의 핵심을 **상황에 따른 선택·휴대·레이어링·소장**으로 설명하고, 경쟁사·포지셔닝 이미지는 독특한 조형과 지속적으로 쓰는 향을 목표로 놓는다. 따라서 이 페이지는 옅어지는 향과 무거운 유리병만을 출발점으로 삼던 이전 서사를 교체하고, **향을 고른 뒤 하루 동안 어떻게 관계를 이어갈 것인가**라는 브랜드 질문에 집중한다. 시장 조사 결과와 비교 도식은 04, 해결할 문제의 정식 정의는 05에서 다룬다.

| 파일 | 관찰한 레이아웃 원리 | 밀도에서의 판단 |
| --- | --- | --- |
| 3-1 | 큰 생활 공간 사진을 왼쪽에 두고, 오른쪽에 작은 보조 사진·짧은 제목·이야기를 배치한다. | **외출 전 향을 고르는 큰 장면과 짧은 이야기**만 가져온다. 작은 보조 사진은 사용자의 선호에 따라 제외한다. |
| 3-2 | 전체 배경 사진 위에 긴 소개, 원형 키워드, AS-IS/TO-BE 항목을 한 화면에 쌓는다. | 정보가 많아 기획 계기보다 분석 결과처럼 읽힌다. 배경에서는 화면 분할과 긴 비교표를 사용하지 않는다. |
| 3-3 | 어두운 배경에 통계 차트·솔루션 원·완성 제품을 함께 제시한다. | 조사 수치와 해결책은 뒤 섹션의 역할이다. 출발점에 근거 없는 수치를 만들지 않는다. |
| 3-4 | 위에는 조사 질문, 아래에는 응답 카드를 반복해 인터뷰 근거를 보여준다. | 질문을 한 줄로 남기는 방식은 유용하다. 응답 카드는 실제 인터뷰 근거가 필요하므로 배경 페이지에 넣지 않는다. |
| 3-5 | 왼쪽의 순간을 담은 사진과 오른쪽의 짧은 개념을 나누어 과거의 장면에서 브랜드 생각으로 이동한다. | **한 순간에서 기획 질문으로 넘어가는 흐름**을 가져온다. 둥근 키워드 두 개나 불꽃 이미지는 복제하지 않는다. |
| 3-6 | 왼쪽의 문제 문장과 AS-IS/TO-BE, 오른쪽의 큰 사용 맥락 사진을 결합한다. | 사진이 실제 사용 맥락을 보여주는 점은 참고한다. 비교표는 05 문제정의와 겹쳐 제외한다. |

### 선택한 레이아웃과 이유

- **왼쪽 0~1010px:** 외출 전 향과 일상의 소지품을 고르는 한 장면만 둔다. 02의 가방에 걸린 완성 제품 컷과 달리, 이 화면은 **아직 어떤 향을 어떻게 쓸지 결정하는 순간**에 집중한다. 회색은 사진 자리 표시다.
- **오른쪽 1200~1790px:** 작은 섹션명 → 28px·보통 굵기 제목 → 14px 기획 서사 → 구분선 아래 20px 질문의 순서다. 본문은 ‘향의 선택’에서 ‘하루의 사용’으로 관심이 옮겨 간 이유를 설명하고, 하단 질문은 지속적 경험의 가능성을 묻는다.
- **수정 결정:** 보조 이미지는 시선을 분산시킨다는 사용자 의견을 반영해 제거한 상태를 유지한다. 사진 한 장과 짧은 글만으로 전통 마패의 **지니는 표식**과 향의 반복 사용을 연결한다.
- **내용의 경계:** 휴대·레이어링·소장은 사용자 제공 자료의 **브랜드 기획 방향**이다. 이 페이지에서 소비자 불편이나 경쟁사의 빈자리를 검증된 사실로 주장하지 않는다. 구체적인 1·2·3마패와 레시피 카드는 04 이후에 소개한다.

## 04 리서치 레퍼런스 분석

`리서치.txt`의 네 항목은 시장·소비자 선택 경험, 경쟁 브랜드, 기획 계기와 새로운 경험, 향 선택 방식이다. 기획 계기는 03에서 이미 제시했으므로 **소비자 선택(04-01)**, **경쟁 사례(04-02)**, **시장 맥락(04-03)**, **포지셔닝 가설(04-04)**로 나눈다. 마지막 화면은 새로 제공된 경쟁사·포지셔닝 이미지를 08의 확정 포지셔닝에 앞서 분석하는 자리다. 한 페이지에 차트·비교·시장 자료를 모두 넣으면 작은 타이포와 여백을 유지하기 어렵다.

| 파일 | 관찰한 레이아웃 원리 | 밀도에 적용한 판단 |
| --- | --- | --- |
| 4-1 | 여러 근거 영역을 왼쪽에 모으고, 검은 전략 영역을 오른쪽에 세워 결론을 분명히 한다. | **04-02에서 제공된 경쟁사 네 곳을 2×2로 묶고, 밀도의 기획 방향을 오른쪽 어두운 영역에 둔다.** SWOT 항목은 자료가 없어 만들지 않는다. |

### 확인한 자료와 해석의 범위

- [오픈서베이 뷰티 트렌드 리포트 2025 요약](https://blog.opensurvey.co.kr/article/beauty-2025-2/)은 전국 만 15~59세 여성 1,000명을 대상으로 한 조사라고 밝힌다. 발행사 요약에는 본인 사용 향수의 최근 1년 구매 경험 **43.9%**, 향수 구매 기준 중 ‘내 취향’ **67.9%**, ‘추구 이미지’ **39.0%**, 탐색 채널인 백화점 브랜드 매장 **39.4%**·올리브영 **28.7%**·면세점 **27.1%**가 실려 있다. 04-01에는 선택 기준과 탐색 채널을 표시했다. 이 표본을 전체 성별·연령의 소비자나 밀도의 잠재 고객 전체로 확대하지 않는다. 요약 기사에 각 향수 세부 문항의 표본수가 따로 적혀 있지 않으므로 별도 응답자 수를 만들어 붙이지 않는다.
- 앞선 시안에서 확인한 [조 말론 런던의 공식 Scent Layering 안내](https://www.jomalone.com/scent-layering)와 [탬버린즈의 공식 퍼퓸 밤 보타리 페이지](https://www.tamburins.com/kr/item/12001516/)는 레이어링과 휴대형 제품의 선행 사례다. 새로 받은 경쟁사 이미지의 비교 대상이 **클린·본투스탠드아웃·탬버린즈·취**이므로 04-02 화면은 사용자 자료의 네 브랜드에 맞춰 다시 구성했다. 이 화면의 브랜드별 평가는 제공 자료의 **기획 해석**으로 표시하고 공식 사실이나 조사 결과로 승격하지 않는다.

[국립중앙박물관·국립박물관문화재단 발표](https://www.museum.go.kr/MUSEUM/contents/M0701040000.do?arcId=23781&catCustomType=post&catId=93&schM=view)에 따르면 2026년 상반기 **뮷즈 매출은 218억 원**이다. 이는 **문화유산 상품의 인접 사례**이며 향수 구매 수요를 나타내지 않는다. 두 값은 사용자 제공 시장 조사 원문의 핵심 방향을 검토하기 위해 04-03에 사용했다.

**디자인 결정:** 원본 이미지의 제품 사진과 큰 주황 원을 복제하지 않고, 04-02에서는 네 경쟁사의 **차별화 단서**, 04-04에서는 **목표 위치와 그 이유**를 분리한다. 오른쪽 해석 영역은 ‘밀도가 어떻게 지속적 향을 만들 것인가’를 1·2·3마패, 휴대, 레시피 카드, 소장과 연결한다. 이 주장은 사용자 검증 전 설계 의도다. 08에서는 실제 비교 기준과 사용자 인식 자료가 확보될 때 위치를 다시 판단해야 한다.

**앞선 화면 수정:** 01은 ‘지니는 향’으로 브랜드의 첫인상을 맞췄다. 02의 세 번째 키워드는 휴대만 말하지 않고 소장까지 포함하며, 소개 문장에도 선택·레이어링·수집의 흐름을 반영했다. 03은 이전의 유리병 휴대 불편 중심 서사를 **향을 고른 뒤에도 이어지는 경험이라는 출발 질문**으로 교체했다. 04-01의 결론은 취향 선택과 시향에서 일상 재사용까지 이어지도록 수정했고, 04-03의 접점에는 소장을 더했다. 05에는 새 경쟁 구도를 별도 근거 성격으로 적고, 시장의 빈자리가 검증된 듯 단정하던 문제 문장을 **검증할 질문**으로 바꿨다.

### 화면 구성

- **04-01 소비자 선택:** 4-2의 시선 흐름을 적용한다. 왼쪽 둥근 자료 영역의 **67.9% 대형 도넛**에서 시작해 39.0% 보조 도넛을 읽고, 오른쪽의 **탐색 장소 세 항목을 하나의 가로 막대 도표**에서 비교한 뒤 하단의 어두운 해석 띠로 끝난다. 4-4처럼 각 영역의 질문과 조사 범위를 먼저 보인다. 왼쪽 도넛은 항목별 100% 대비 응답률이며, 오른쪽 막대는 모두 같은 **0~50% 축**을 쓴다. 장소는 순서형 자료가 아니므로 점을 잇는 선 그래프 대신 가로 막대를 사용한다.
- **04-02 경쟁 사례:** 4-1의 근거→전략 구도를 밀도에 맞게 변형한다. 사용자 제공 경쟁사 이미지의 **클린·본투스탠드아웃·탬버린즈·취**를 왼쪽 2×2 카드로 비교하고, 오른쪽 어두운 영역에 밀도의 **휴대·레이어링·소장** 방향을 둔다. 카드 문구는 제공 자료의 해석으로 표시하며 경쟁사의 부족함으로 단정하지 않는다.
- **04-03 시장 맥락:** 4-3의 큰 곡선과 세 자료 영역을 적용한다. 43.9% 국내 향수 구매 경험, +39.5% 향수 수출 증가, 218억 원 문화유산 상품 매출을 **서로 다른 지표로** 나란히 놓고 하단에 밀도의 기획 접점을 적는다. 이 페이지는 밀도 제품의 예상 매출이나 확정 수요를 계산하는 자료가 아니다.
- **04-04 포지셔닝 가설:** 제공된 두 축과 상대 위치를 이름표와 얇은 선으로 다시 그린다. 제품 사진은 비교 도식의 핵심이 아니므로 반복하지 않는다. 밀도의 목표 위치는 진하게 표시하지만, 점의 좌표는 **정량값이 없는 기획 판단**임을 제목과 하단 주석에 적는다. 오른쪽에는 ‘지속적 향’을 실제 경험으로 만들 선택·휴대·겹쳐 쓰기·소장을 서술한다.
- **이전 시안의 오류:** 같은 크기의 도넛 다섯 개와 일반적인 비교 행은 레퍼런스의 화면 위계가 빠진 결과였다. 차트 형태만 참고한 수준을 넘어, **어느 근거를 먼저 보고 어떤 해석에 도착하는지**를 레이아웃에 반영했다.

## 05 문제정의 레퍼런스 분석

`문제 정의.txt`는 리서치에서 발견한 기회와 해결할 문제를 요구한다. 이 페이지는 확인된 소비자 선택 자료 1개와 사용자 제공 시장 조사 문서의 **사용 장면 가설**, **경쟁사·포지셔닝 해석**을 구분해 놓고, 한 문장 질문과 밀도의 기획 기회로 이어간다.

| 파일 | 관찰한 레이아웃 원리 | 밀도에 적용한 판단 |
| --- | --- | --- |
| 5-1 | 문제 항목에서 아래의 가설 항목으로 화살표가 내려간다. | **위에서 아래로 추론이 진행되는 구조**를 가져온다. 세 가지 문제를 모두 검증된 사실인 것처럼 반복하지 않는다. |

| 5-4 | 문제·해결 3열을 반복하고 하단 곡선에 목표를 놓는다. | 문제에서 목표로 내려가는 흐름만 참고한다. 색과 같은 모양의 6개 카드는 복제하지 않는다. |
| 5-5 | 넓은 여백 속 AS-IS/TO-BE를 얇고 둥근 행으로 제시한다. | 05의 둥근 문제·기회 영역과 작은 글자 비율에 반영한다. |
| 5-6 | 상단 근거 세 개가 아래의 사용자 문제로 이어진다. | **05의 세 근거 열과 아래 문제 문장**에 적용한다. 근거 성격이 서로 다르므로 열마다 ‘확인된 조사’와 ‘브랜드 자료 가설’을 표시한다. |
| 5-7 | 문제와 해법을 선으로 1:1 연결한다. | 하나의 가설에서 하나의 방향으로 이어지는 관계만 가져온다. 지원되지 않는 문제 3개와 해결책 3개를 단정하지 않는다. |
| 5-8 | 큰 프로젝트 목표 아래 AS-IS/TO-BE를 둥근 형태로 분리한다. | 문제 가설을 옅은 영역에, 밀도의 제안을 진한 영역에 두어 **현재 가정 → 제안**의 순서를 만든다. |

### 05 화면의 문구 경계

- 상단 첫 열의 67.9%·39.0%는 [오픈서베이 원문](https://blog.opensurvey.co.kr/article/beauty-2025-2/)에서 확인한 수치다. 두 번째 열의 사용 장면과 세 번째 열의 경쟁 구도는 사용자 제공 자료에서 가져온 **브랜드 기획·해석**이며 실제 사용자 조사로 검증되지 않았다.
- 가운데 문장은 ‘향 선택에서 하루의 재사용으로 이어지는 경험’을 확인할 **검증 전 질문**이다. 하단은 밀도의 **기획 제안**이다. 1·2·3마패와 레시피 카드, 소장 경험은 사용자 제공 자료의 브랜드 방향에서 왔다.
