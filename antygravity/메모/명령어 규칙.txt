================================================================================
                    [ 사용자 키워드 및 실행 명령어 규칙 ]
================================================================================

본 문서는 사용자가 입력하는 특수 명령 키워드(예: "실행 시작", "리서치 자료 추가 입력" 등)에 
따라 AI Agent가 자동으로 인식하여 즉시 수행해야 하는 명령어별 실행 트리거 및 동작 규정집입니다.

--------------------------------------------------------------------------------
1. 핵심 실행 키워드 및 트리거 동작 규칙
--------------------------------------------------------------------------------

[명령어 1] "실행 시작" / "분석 시작" / "스킬 실행"
 ▶ 역할: 홈페이지 레퍼런스 종합 분석 스킬(homepage-reference-analyzer) 즉시 실행
 ▶ Agent 트리거 동작:
    1) 워크스페이스 내 파일명에 `[리서치 결과]`가 포함된 모든 `.txt` 파일 탐색 및 자동 수집
    2) 8단계 분석 알고리즘(개별분석 -> 그룹화 -> 비율집계 -> 수치패턴 30%/10% -> 공통/차이점 -> 장단점 -> 인사이트 -> 추가조사) 실행
    3) 100개 단위 원자적 분할 저장 규칙 준수 (메모장 1개당 최대 100개 항목 제한, 분할 시 항목 보존)
    4) `output/` 폴더 내 아래 3종 UTF-8 `.txt` 보고서 파일 생성:
       - `output/01_개별분석_001-100.txt` (100개 초과 시 `101-200` 연번 분할 파일명 사용)
       - `output/02_전체비교분석.txt`
       - `output/03_최종인사이트.txt`
    5) 작업 완료 후 생성된 파일의 상대 경로 및 핵심 분석 내용 요약 보고

[명령어 2] "리서치 자료 추가 입력"
 ▶ 역할: 추가 레퍼런스 자료 동적 수집 모드 전환
 ▶ Agent 트리거 동작:
    1) 명령 직후 사용자가 추가로 입력/제공하는 파일, URL, 텍스트를 추가 자료로 자동 감지 및 수집
    2) 비파괴 관리: 기존 자료를 덮어쓰지 않고 항상 누적 저장 및 분석에 병합
    3) 출처 구분: 분석 보고서 상에 해당 항목이 `[기본자료]` 출처인지 `[추가자료]` 출처인지 명시
    4) 중복 통합: 동일 브랜드/홈페이지 중복 시 1개 항목으로 합치되 발견된 모든 출처 기록

[명령어 3] "가상 클라이언트 생성" / "신규 클라이언트 분석"
 ▶ 역할: 9단계 프로세스 기반 신규 가상 클라이언트 기획서 작성
 ▶ Agent 트리거 동작:
    1) 클라이언트 일회성 생성 원칙: 기존에 사용된 클라이언트 프로필(이름, 브랜드, 요구사항 등)은 재사용 금지
    2) 기존과 겹치지 않는 신규 가상 클라이언트 정보 동적 생성
    3) `가상 클라이언트/가상 클라이언트 기반 분석 결과 작성 양식.md` 9단계 프로세스 및 6대 필수 작성 양식으로 작성
    4) `가상 클라이언트/` 디렉토리에 마크다운 보고서 저장

[명령어 4] "웹사이트 생성" / "웹사이트 3대 문서 병합"
 ▶ 역할: 사단 브랜드 클라이언트 대상 5가지 시안 기획 및 최적 요소 병합 문서 도출
 ▶ Agent 트리거 동작:
    1) '사단' 브랜드 프로젝트 클라이언트 요구사항 파악
    2) 사이트맵, 서비스 흐름도, 화면 설계서 각 영역별 5가지 시안(Ver 1~5) 기획·비교
    3) 영역별 최적 요소만 통합한 단 하나의 병합 `.md` 생성 및 지정 폴더 저장:
       - 사이트맵 병합 ➔ `[사이트맵]` 폴더 / `사이트맵_병합_[클라이언트이름].md`
       - 서비스 흐름도 병합 ➔ `[서비스 흐름도]` 폴더 / `서비스_흐름도_병합_[클라이언트이름].md`
       - 화면 설계서 병합 ➔ `[화면 설계서 제작]` 폴더 / `화면_설계서_병합_[클라이언트이름].md`

[명령어 5] "사이트맵 제작" / "서비스 흐름도 제작" / "화면 설계서 제작" / "메인페이지 스토리보드 제작"
 ▶ 역할: Antigravity 프롬프트 명세 기반 영역별 3종 산출물 세트 즉시 생성
 ▶ Agent 트리거 동작:
    - "사이트맵 제작" ➔ `사이트맵.md`, `사이트맵.mmd`, `사이트맵.svg` 생성 (계층 구조, Mermaid 포함)
    - "서비스 흐름도 제작" ➔ `서비스_흐름도.md`, `서비스_흐름도.mmd`, `서비스_흐름도.svg` 생성 (진입~결과 흐름 및 분기)
    - "화면 설계서 제작" ➔ `화면_설계서.md`, `와이어프레임.html`, `화면_목록.json` 생성 (단독 실행 가능 HTML 포함)
    - "메인페이지 스토리보드 제작" ➔ `메인페이지_스토리보드.md`, `메인페이지_스토리보드.html`, `스토리보드_목록.json` 생성 (화면/섹션별 독립 표 구조)

[명령어 6] "4단계 입력" / "5단계 입력"
 ▶ 역할: 분석 분류 기준(4단계) 및 정리 포맷(5단계) 지침 업데이트
 ▶ Agent 트리거 동작:
    1) 사용자가 추가 제공하는 4단계(분류 기준) 또는 5단계(정리 포맷) 내용을 수신
    2) `SKILL.md` 및 관련 스킬 명세 문서의 보류(TBD) 섹션에 즉시 반영하여 업데이트

--------------------------------------------------------------------------------
2. 모든 명령어 실행 시 Agent 공통 준수 사항
--------------------------------------------------------------------------------
 1) 모든 생성 파일은 **UTF-8 인코딩**을 사용한다.
 2) 원본 리서치 데이터 및 기존 작업 파일은 절대로 수정하거나 덮어쓰지 않는다.
 3) 외부 디자인 도구(Figma 등) 없이 로컬 CLI 및 브라우저에서 바로 확인 가능한 독립 파일로 도출한다.
 4) 명령어 수행이 완료되면 생성된 파일의 상대 경로와 핵심 결과 요약을 직관적으로 보고한다.
