# 📌 [화면 설계서 시안 2] 최하은 클라이언트 - 3D 각인 캔버스 중심 화면 설계

## 1. 시안 개요 및 레이아웃 아키텍처
- **레이아웃 타입:** **Type C (분할 스크롤 듀얼 레이아웃)**
- **특징:** 좌측 50% 영역에 360도 회전 3D 마패 각인 용기 고정 뷰어를 배치하고, 우측 50% 영역에서 서체 선택 및 문구 입력을 지원하는 듀얼 아키텍처.

---

## 2. 5대 화면 영역 구성 명세

```text
+-----------------------------------------------------------------------+
| [Header] 로고(士團) | 3D Engraving | Note Mixer | Eco Sub | Quick Cart |
+-----------------------------------------------------------------------+
| [Left: 3D Fixed Viewport (50%)]  | [Right: Engraving Control (50%)]   |
|  - 360도 3D 마패 용기 렌더링     |  - 서체 선택 (훈민정음/서예/영문)  |
|  - 회색 UI 캔버스 회전 드래그    |  - 각인 문구 입력 (최대 10자)       |
|  - 실시간 각인 투영 Renders      |  - 추천 사자성어 탭 UI             |
+-----------------------------------------------------------------------+
| [Aside Area] Sticky Floating CTA | 각인 문구 및 선택 향 콤보 가격 요약|
+-----------------------------------------------------------------------+
| [Footer] 브랜드 헤리티지 | 오시는 길 | 이용 약관                      |
+-----------------------------------------------------------------------+
```

---

## 3. 핵심 10대 콘텐츠 & 기능 요소
- **콘텐츠 (10개):** 3D 용기 렌더링 캔버스, 훈민정음 한자 서체표, 서예 한글 서체표, 영문 각인 템플릿, 사자성어 각인 가이드, 마패 질감 이미지, 비단 포장 룩북, 고객 리뷰 갤러리, 비건 인증서, CS 안내
- **기능 (10개):** 3D 용기 360도 드래그 회전, 텍스트 실시간 3D 투영, 서체 변경 필터, 사자성어 1-Click 입력, 줌인/줌아웃 조절, 2D 회생 백업 뷰어 스위치, 장바구니 담기, 각인 캡처 이미지 저장, 선물 포장 체크박스, 라이브 챗
