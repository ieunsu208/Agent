# 📌 [화면 설계서 시안 4] 최하은 클라이언트 - 친환경 카트리지 구독 중심 화면 설계

## 1. 시안 개요 및 레이아웃 아키텍처
- **레이아웃 타입:** **Type E (하단 시트 모바일 앱 레이아웃)**
- **특징:** 모바일 최적화 하단 슬라이딩 시트 UI를 활용하여 친환경 리필 카트리지 정기 구독 배송일 설정과 공병 반납 회수를 간편하게 지원하는 레이아웃.

---

## 2. 5대 화면 영역 구성 명세

```text
+-----------------------------------------------------------------------+
| [Header] 로고(士團) | 친환경 에코 뱃지 | 공병 회수 리워드 마이페이지 |
+-----------------------------------------------------------------------+
| [Body Area]                                                           |
|  - 친환경 카트리지 구독 플랜 (1개월 / 2개월 / 3개월 콤보 카드)       |
|  - 공병 반납 가이드 & 어사 리워드 포인트 누적 현황                    |
+-----------------------------------------------------------------------+
| [Bottom Sheet UI (Mobile/Desktop Overlay)]                            |
|  - 회수 배송지 입력 폼                                                |
|  - 공병 수거 전용 바코드 생성기                                       |
|  - 3D 각인 마패 용기 재사용 등록 체크                                 |
+-----------------------------------------------------------------------+
| [Aside Area] 구독 할인가 적산 계산기 | Sticky Quick Sub CTA           |
+-----------------------------------------------------------------------+
| [Footer] 에코 패키징 정책 | CS 센터 | 개인정보 처리 방침             |
+-----------------------------------------------------------------------+
```

## 3. 핵심 10대 콘텐츠 & 기능 요소
- **콘텐츠 (10개):** 리필 카트리지 3종 이미지, 공병 반납 프로세스 도해, 어사 리워드 포인트 수치, 구독 주기 카드, 에코 패키징 소재 설명, 화해 비건 성분표, FAQ, 고객 후기, 회수 택배 안내, CS 센터
- **기능 (10개):** 구독 주기 슬라이더 선택, 공병 회수 신청 폼, 바코드 자동 생성, 3D 용기 재사용 선택, 정기 결제 카드 등록, 포인트 자동 차감, 카톡 알림톡 신청, 구독 일시정지 버튼, 수량 변경, 라이브 챗
