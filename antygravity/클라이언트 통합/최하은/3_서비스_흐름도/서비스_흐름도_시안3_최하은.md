# 📌 [서비스 흐름도 시안 3] 최하은 클라이언트 - 노트 믹싱 밸런서 직접 조정 플로우

## 1. 시안 개요 및 서비스 시나리오
- **시나리오 컨셉:** Top/Middle/Base 향 노트를 사용자가 직접 정교하게 믹싱하는 **Pro Artisan Mixer Flow**.
- **주요 대상:** 니치 향수 마니아 및 커스텀 조향 지식이 있는 고객.

---

## 2. 세부 단계별 사용자 행동 & 시스템 반응 명세

| 단계 | 사용자 행동 | 시스템 반응 & UX 로직 | 입출력 데이터 |
| :---: | :--- | :--- | :--- |
| **Step 1** | 메인 Note Mixer 메뉴 클릭 | 조향 랩 3D 슬라이더 인터페이스 활성화 | 입력: 메뉴 클릭 / 출력: T/M/B 조향판 노출 |
| **Step 2** | Top/Middle/Base 슬라이더 조절 | 향 성상 피라미드 및 잔향 시간 계산기 업데이트 | 입력: 드래그 믹싱 비율 / 출력: 향 피라미드 그래프 |
| **Step 3** | 화해 비건 성분 확인 | 비건 성분 및 알레르기 유발 성분 아코디언 확인 | 입력: 성분 아코디언 클릭 / 출력: 성분 안전성 데이터 |
| **Step 4** | 용기 3D 각인 신청 | 마패 용기에 3D 서체 및 메시지 추가 | 입력: 각인 텍스트 / 출력: 3D 마패 각인 시뮬레이션 |
| **Step 5** | 주문 결제 완료 | 나만의 커스텀 포뮬러 레시피 넘버 발급 및 결제 | 입력: 결제 정보 / 출력: 커스텀 레시피 넘버 카드 |

---

## 3. 시안 3 유저플로우 다이어그램 (Mermaid)
```mermaid
flowchart LR
    Start([방문자 진입]) --> Mixer[T/M/B 노트 슬라이더 믹싱]
    Mixer --> Safety[화해 비건 성분 확인]
    Safety --> Engrave[3D 각인 신청]
    Engrave --> Checkout[주문 결제 & 레시피 넘버 발급]
```

## 4. 장단점 및 병합 시 참고 포인트
- **장점:** 조향의 자유도가 매우 높고 성분 안전성 정보가 완벽하게 제공됨.
- **단점:** 조향 초보자에게는 비율 조합 설정 부담이 있을 수 있으므로 AI 추천 비율 자동 설정 버튼 연동 필요.
