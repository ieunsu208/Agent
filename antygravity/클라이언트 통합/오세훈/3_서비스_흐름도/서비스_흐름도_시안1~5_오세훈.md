# 📌 [서비스 흐름도 개별 시안 1~5] 오세훈 (조선 왕실 의궤 조향 복원 연구원)

## 1. 개별 시안 1: 고문헌 원전 탐색 직행 플로우 (Academic Direct Flow)
* **진입:** 역사 연구 포털 / 고문헌 검색 유입
* **흐름:** 메인 ➔ 의궤 원문 검색 ➔ 3D 고서 뷰어 ➔ 한자/한글 대조 ➔ 조향 성분표 확인 ➔ 복원 보틀 구매

## 2. 개별 시안 2: 인터랙티브 3D 플립 탐색 플로우 (3D Flip Interactive Flow)
* **진입:** SNS 미디어아트 광고 및 인터랙티브 웹 큐레이션 유입
* **흐름:** 3D 고서 히어로 ➔ 마우스 드래그로 책장 넘기기 ➔ 향기 피어오름 애니메이션 ➔ 복원 에디션 선택 ➔ 장바구니

## 3. 개별 시안 3: 프리미엄 오동나무 패키지 선물 플로우 (Luxury Gift Concierge Flow)
* **진입:** VIP 명절/기념일 하이엔드 선물 검색 유입
* **흐름:** 선물 전용관 ➔ 오동나무 옻칠함 옵션 선택 ➔ 안동 한지 보자기 색상 지정 ➔ 축문/각인 메시지 입력 ➔ 선물 포장 결제

---

## 4. 개별 시안 4: 원료 산지 역추적 탐색 플로우 (Origin Tracing Flow)

* **흐름:** 조선 8도 지도 ➔ 오대산/지리산 핀 클릭 ➔ 100% 쌀 발효 주정 인증서 확인 ➔ 싱글 오리진 향수 선택 ➔ 결제

## 5. 개별 시안 5: 의궤 보존 후원 & VIP 레지스트리 플로우 (Patron Registry Flow)
