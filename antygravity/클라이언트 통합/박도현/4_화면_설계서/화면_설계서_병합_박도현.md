## 1. 컴포넌트 단위 Wireframe 아키텍처 명세 (6대 세부 고도화)

### 1) SEC-01 Header Component
- **배치**: top:0 고정 sticky flexbox (height: 80px)
- **속성**: display: flex; justify-content: space-between; align-items: center; padding: 0 40px; background: #0F172A;
- **전환**: 768px 미만 모바일 햄버거 토글 드롭다운 스위칭

### 2) SEC-02 Hero Component
- **배치**: height: 600px; display: grid; grid-template-columns: 1fr 1fr; gap: 24px;
- **내용**: 좌측 한옥 브랜드 헤리티지 헤드라인, 우측 3D 마패 오브제 회색 박스

### 3) SEC-03 Product Showcase Component (★ 필수배치)
- **배치**: display: grid; grid-template-columns: repeat(3, 1fr); gap: 32px; padding: 60px 40px;
- **내용**: 
  - 카드 1: 1마패 단아한 자수 패키지 (50ml)
  - 카드 2: 2마패 놋쇠 레거시 패키지 (100ml)
  - 카드 3: 3마패 왕실 실버 패키지 (컬렉터스 킷)

### 4) SEC-04 Custom Studio Component
- **배치**: 50:50 듀얼 스플릿 Grid;
- **내용**: 3D 레이저 각인 미리보기 캔버스 + 초성/한자 레이저 옵션 컨트롤러

### 5) SEC-05 Discovery Quiz & Mixer Component
- **배치**: 5단계 스텝 문답 인터랙션 카드 카러셀

### 6) SEC-06 Vegan & Ingredients Component
- **배치**: 4대 친환경 인증 마크 4열 카드 그리드

### 7) SEC-07 Reservation & Subscription Component
- **배치**: 한옥 조향 클래스 캘린더 피커 & 정기구독 선택 서브 폼

### 8) SEC-08 Footer Component
- **배치**: 4열 그리드 사업자 정보 & 1:1 라이브 챗 링커

## 2. 10대 콘텐츠 세부 데이터 정의

1. **CONT-01**: 메인 히어로 타이틀 ("조선 암행어사 마패의 향을 담다, 사단(士團)")
2. **CONT-02**: 히어로 서브 서사 카피 ("한옥의 여백과 놋쇠의 울림이 전하는 오리엔탈 하이엔드 니치 퍼퓸")
3. **CONT-03**: 1마패 자수 팩 데이터 (단아한 실크 패브릭 자수, 50ml, W95,000)
4. **CONT-04**: 2마패 놋쇠 팩 데이터 (장인 수제 놋쇠 용기, 100ml, W185,000)
5. **CONT-05**: 3마패 실버 팩 데이터 (왕실 실버 봉인 실린더, 100ml, W280,000)
6. **CONT-06**: 3D 각인 텍스트 데이터 (최대 6글자 한글/한자/영문)
7. **CONT-07**: 조향 퀴즈 5문답 진단 알고리즘표
8. **CONT-08**: 4대 비건 인증 마크 (K-Vegan, ECOCERT, IFRA Safety, Leaping Bunny)
9. **CONT-09**: 한옥 클래스 타임슬롯 피커 (10:00 / 14:00 / 17:00 세션)
10. **CONT-10**: 사업자 등록 정보 및 1:1 카톡 상담 링크 데이터

## 3. 10대 기능 UI/UX 인터랙션 명세

1. **FUNC-01**: GNB 드롭다운 메가 메뉴 hover 트랜지션 (opacity 0->1, 0.3s)
2. **FUNC-02**: 쇼케이스 카드 hover 시 3D 파츠 원료 팝업 노출
3. **FUNC-03**: 3D 각인 텍스트 실시간 Canvas 렌더링
4. **FUNC-04**: 각인 소재(놋쇠 / 실버 / 자수) 스위칭 시 실시간 가격 변경 엔진
5. **FUNC-05**: 퀴즈 선택 시 다음 문답 카드 슬라이드 인터랙션
6. **FUNC-06**: 원료 성분 카드 클릭 시 원산지 지도 오버레이 팝업
7. **FUNC-07**: 한옥 오프라인 클래스 캘린더 날짜 선택 기능
8. **FUNC-08**: 타임슬롯 마감 시 disabled 처리 및 알림 신청 팝업
9. **FUNC-09**: 정기구독 배송 주기(1달 / 3달 / 6달) 탭 전환
10. **FUNC-10**: 3개국어(KOR / ENG / CHN) 언어 스위치 토글

## 4. 예외 처리 & 유효성 검증 명세

- **EXC-01**: 각인 텍스트 6자 초과 입력 시 경고 툴팁 및 자동 입력 차단
- **EXC-02**: WebGL/3D 각인 캔버스 로딩 실패 시 2D 플랫 그래픽 자동 대체 스위칭
- **EXC-03**: 한옥 예약 타임슬롯 중복 클릭 시 마감 안내 모달 렌더링

## 5. 반응형 Breakpoints 변환 명세

- **Desktop (1440px+)**: 3열 카드 그리드, 50:50 듀얼 스플릿 캔버스
- **Tablet (768px ~ 1023px)**: 2열 카드 그리드, 퀴즈 세로 스택
- **Mobile (375px ~ 767px)**: 1열 카러셀 가로 스와이프 스위칭, GNB 햄버거 슬라이드 메뉴
