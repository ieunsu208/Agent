# 📌 [서비스 흐름도 개별 시안 1~5] 조민재 (어번 나이트 & 오리엔탈 스모키 마스터)

## 1. 개별 시안 1: 스모키 칵테일 페어링 직행 플로우 (Pairing Direct Flow)

* **흐름:** 메인 ➔ 페어링 바 ➔ 전통주 칵테일 선택 ➔ 추천 스모키 향수 확인 ➔ 본품 구매

## 2. 개별 시안 2: 놋쇠 인센스 홀더 오브제 쇼핑 플로우 (Incense Object Flow)

* **흐름:** 인센스 랩 ➔ 3D 연기 모션 감상 ➔ 놋쇠 마패 홀더 & 죽탄 스틱 선택 ➔ 장바구니

## 3. 개별 시안 3: 비밀 심야 바 암행 패스 예약 플로우 (Secret Pass Booking Flow)

* **흐름:** 심야 바 예약관 ➔ 날짜/시간(22:00~02:00) 선택 ➔ 예약금 결제 ➔ 모바일 비밀 암호 코드 발급

---

## 4. 개별 시안 4: 조선 순라군 야행 서사 플로우 (Night Patrol Narrative Flow)

* **흐름:** 야행록 에디토리얼 ➔ 3대 딥 스모키 노트 탐색 ➔ 50ml 보틀 각인 ➔ 결제
