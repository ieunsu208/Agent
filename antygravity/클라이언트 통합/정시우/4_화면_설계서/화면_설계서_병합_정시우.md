## 4. 예외 처리 & 데이터 유효성 검증 명세 (Validation & Exception Logic)

1. **입력 유효성 검증 (Input Validation):**
   - 각인 문구 입력 폼: 최대 한자 6자, 한글 12자 이내 제한. 초과 입력 시 `border: 2px solid #ef4444` 처리 및 "각인 가능 글자 수를 초과했습니다." 경고 툴팁 표출.
2. **3D GLTF 렌더링 지연/오류 예외 처리:**
   - 사용자 브라우저가 WebGL을 지원하지 않거나 3D 자산 로딩 시간이 3초를 초과할 경우, **2D 무채색 회색 고해상도 놋쇠 용기 플레이스홀더 와이어프레임 이미지**로 자동 스위칭 fall-back 렌더링.
3. **VIP 회원 등급 불일치 예외 처리:**
   - 비회원 또는 1마패 회원이 3마패 전용 디스커버리 수강권을 클릭할 경우 ➔ "3마패 어사 VIP 회원 전용 혜택입니다. 등급 업그레이드 조건을 확인하세요." 팝업 안내 모달 발동.

## 5. 반응형 디바이스별 레이아웃 변환 명세 (Responsive Breakpoints)

* **Desktop (1440px 이상):** 좌측 280px 고정 사이드바 + 우측 70:30 비대칭 럭셔리 매거진 구도 유지.
* **Tablet (768px ~ 1023px):** 좌측 사이드바가 상단 슬라이딩 헤더 메뉴로 변환, 우측 70:30 비대칭 구도가 1:1 균등 2열 카드로 변환.
* **Mobile (375px ~ 767px):** 사이드바가 햄버거 모달 메뉴로 숨김 처리, 우측 전 코드가 **1열 수직 스택(Vertical Single Column)**으로 변환되며 하단에 **[👑 VIP 혜택 적용 & 각인 주문하기] 고정 스티키 바(Bottom Sticky Bar)** 생성.
