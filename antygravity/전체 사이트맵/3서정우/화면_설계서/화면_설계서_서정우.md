## 3. 화면별 상세 사양 (Screen Specifications)

### 3.1 P-CUST-01-01: 3D 실시간 커스텀 UI
- **목적:** 사용자가 이탈리안 베지터블 가죽 4종과 붓글씨 텍스트 각인을 실시간 3D 360도로 확인 및 조합
- **진입 조건:** `P-CUST-01` 또는 메인 홈에서 [3D 커스텀 시작] 클릭
- **종료 조건:** [견적/주문하기] 클릭 시 수량 선택 및 주문/견적 폼 모달 이동
- **구성 영역:**
  - **3D 메인 캔버스:** 키링 360도 회전, 마패 텍스트 라이브 렌더링, 황동 링/가죽 고리 조화
  - **가죽 색상 선택 패널:** 이탈리안 탄(기본), 버건디 레드, 딥 네이비, 클래식 차콜 (4종 칩)
  - **각인 문구 입력기:** 한글/영문 붓글씨 텍스트 폼 (최대 10자), 불박 음각 폰트 크기 조절
  - **하단 액션 바:** [완성 샷 캡처 다운로드], [견적 및 주문하기]

---

### 3.2 P-B2B-01-01: B2B 대량 견적 신청 모달
- **목적:** 기업 및 단체 기프트 대량 수량(50개 이상) 문의 접수 및 로고 파일 첨부
- **진입 조건:** GNB [B2B] 또는 우하단 스티키 뱃지 클릭
- **종료 조건:** [견적 신청 확정] 제출
- **유효성 검사 및 에러 문구:**
  - **기업명/담당자:** 필수 작성 (미입력 시 "기업명과 담당자명을 입력해 주세요")
  - **연락처:** 숫자 10~11자리 Regex (오류 시 "올바른 연락처를 입력해 주세요")
  - **수량:** 최소 50개 이상 (50개 미만 입력 시 "50개 미만은 개별 주문 폼을 이용해 주세요")
  - **로고 첨부:** AI, PNG, SVG 파일 확장자 검사 (오류 시 "AI, PNG, SVG 확장자만 가능합니다")

## 4. 반응형 레이아웃 및 접근성 요구사항

- **PC (Desktop >= 1200px):** 좌측 3D 뷰어 (60%) + 우측 커스텀 옵션 패널 (40%) Split 레이아웃
- **Tablet (768px ~ 1199px):** 상단 3D 뷰어 + 하단 가로 스크롤 옵션 패널
- **Mobile (< 768px):** 풀스크린 3D 캔버스 & 하단 Slide-Up 드로어 옵션 바
- **접근성 (WCAG 2.1 AA):**
  - 다크 브라운 `#241810` 배경 대비 황동 골드 `#C89D5C` 및 아이보리 `#F5EBE0` 텍스트 (명암비 6.2:1 준수)
  - 키보드 Tab 이동으로 3D 각인 텍스트 입력 및 컬러 버튼 선택 가능 (`aria-label` 부여)

## 5. 설계 가정 사항 (Assumptions)

1. [가정] B2B 기업 대량 주문(50개 이상) 시 기업 전용 금속 불박 도장을 무료로 제작해 드린다.
2. [가정] 3D 커스텀 완료 후 [완성 샷 다운로드] 클릭 시 고해상도 PNG 이미지가 생성된다.
3. [가정] 모든 견적 문의 접수 시 담당 장인이 24시간 이내에 1:1 유선/카카오톡 상담을 진행한다.
