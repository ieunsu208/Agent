## 2. 화면 ID 규칙 및 전체 화면 목록

- **ID 체계:** `P-[카테고리]-[순번]-[서브순번]`
  - `MAIN`: 메인 홈
  - `INTRO`: 세계관 소개
  - `INFO`: 행사 안내 및 시향 부스 지도
  - `KIT`: 웰컴 키트
  - `PASS`: 얼리버드 예매 모달 및 완료
  - `COMM`: 커뮤니티 및 소셜
  - `SYS`: 시스템 및 약관

| 화면 ID | 화면명 | 화면 유형 | 진입 조건 | 주요 이동 대상 |
| :--- | :--- | :---: | :--- | :--- |
| `P-MAIN-01` | 메인 홈 | 기본 | 서비스 URL 최초 랜딩 | `P-INTRO-01`, `P-INFO-01`, `P-PASS-01-01` |
| `P-INTRO-01` | 브랜드 세계관 | 페이지 | GNB [Intro] 클릭 | `P-INFO-01`, `P-PASS-01-01` |
| `P-INFO-01` | 시향 부스 지도 & 타임테이블 | 페이지 | GNB [Timetable & Map] 클릭 | `P-INFO-01-01-01`, `P-PASS-01-01` |
| `P-INFO-01-01-01`| 부스 향 노트 팝업 | 레이어 팝업 | 부스 지도 핀 클릭 [가정] | `P-PASS-01-01` |
| `P-KIT-01` | 웰컴 키트 안내 | 페이지 | GNB [Welcome Kit] 클릭 | `P-PASS-01-01` |
| `P-PASS-01-01` | 얼리버드 패스 예매 모달 | 모달 | [Pass 예매하기] 버튼 클릭 | `P-PASS-01-02` |
| `P-PASS-01-02` | 예매 완료 & 카카오 알림톡 | 완료 페이지 | 예매 정보 입력 후 유효성 통과 | `P-MAIN-01` |
| `P-PASS-01-03` | 예매 내역 조회 팝업 | 레이어 팝업 | [예매 내역 조회] 클릭 [가정] | `P-PASS-01-02` |
| `P-COMM-01` | 기대평 & 소셜 | 페이지 | GNB [Community] 클릭 | `P-PASS-01-01` |
| `P-SYS-01-01` | 이용약관 / 개인정보방침 | 페이지 | 푸터 약관 링크 클릭 | `P-MAIN-01` |
| `P-SYS-01-02` | 404 / 예외 안내 | 예외 페이지 | 잘못된 URL 또는 네트워크 오류 | `P-MAIN-01` |

## 3. 화면별 상세 사양 (Screen Specifications)

### 3.1 P-MAIN-01: 메인 홈
- **목적:** K-헤리티지 암행어사 분위기 전달 및 얼리버드 패스 예매 유도
- **진입 조건:** 랜딩 URL 접속
- **종료 조건:** [Pass 예매하기] 클릭 시 모달 호출, GNB 메뉴 이동 시 페이지 전환
- **구성 영역 및 UI 요소:**
  - **헤더:** 로고, GNB 탭, 예매 CTA 버튼
  - **히어로 영역:** 3D 어사 출두 트레일러 비디오 (플레이/일시정지, 음소거 토글), 힙트래디션 헤드라인
  - **바디 세션 1:** 페스티벌 핵심 D-Day 및 장소 (성수동 & 경복궁) 요약
  - **바디 세션 2:** 웰컴 키트 굿즈 미니 슬라이더 및 한정 수량 안내
  - **바디 세션 3:** 실시간 기대평 최신 3건 및 [더보기]
  - **스티키 바:** 화면 하단 고정 [1,000명 한정 얼리버드 패스 예매하기 (잔여 티켓 카운터)]
  - **푸터:** 주최 정보, 오시는 길 약도 링크, 약관 링크, SNS
- **상태 정의:**
  - 기본: 3D 비디오 자동 재생 (음소거 상태)
  - 로딩: 비디오 플레이스홀더 이미지 표시
  - 빈 상태: 해당 없음
- **반응형 기준:**
  - Desktop (1200px+): 2열 그리드 및 고화질 비디오
  - Tablet (768~1199px): 1열 수직 재배치, 스티키 바 간소화
  - Mobile (~767px): 풀스크린 비디오, 햄버거 메뉴, 하단 터치 친화 스티키 바

### 3.2 P-PASS-01-01: 얼리버드 패스 예매 모달
- **목적:** 1,000명 한정 페스티벌 패스 예매 및 웰컴 키트 현장 수령 정보 수집
- **진입 조건:** 메인 홈 또는 타 페이지에서 [Pass 예매하기] 클릭
- **종료 조건:** 예매 신청 성공 시 `P-PASS-01-02` 이동, [X] 닫기 시 모달 종료
- **구성 영역 및 UI 요소:**
  - **모달 헤더:** Title "어사 출두 얼리버드 패스 예매", [X] 닫기 버튼
  - **입력 폼 영역:**
    - 방문 일자 선택 (라디오 탭: 10월 20일 / 10월 21일 / 10월 22일)
    - 예매 인원 선택 (드롭다운: 1매 ~ 최대 4매)
    - 예매자 성함 (Input Text, 필수)
    - 휴대전화 번호 (Input Tel, 필수, 숫자 10~11자리)
    - 개인정보 수집 및 동의 (체크박스, 필수)
  - **모달 푸터:** [1,000명 한정 예매 확정하기] 버튼
- **유효성 검사 및 에러 메시지:**
  - 성함 미입력: "예매자 성함을 입력해 주세요." (레드 보더)
  - 연락처 불일치: "올바른 휴대전화 번호를 입력해 주세요. (예: 01012345678)"
  - 약관 미동의: "개인정보 수집 및 활용에 동의해 주세요."
- **상태 정의:**
  - 기본: 첫 번째 날짜 선택 활성화, 버튼 기본 상태
  - 오류: 유효성 미통과 시 에러 문구 노출 및 focus 이동
  - 완료/로딩: 예매 버튼 클릭 시 spinner 동작 후 `P-PASS-01-02` 이동

### 3.3 P-INFO-01: 시향 부스 지도 & 타임테이블
- **목적:** 오프라인 성수/경복궁 시향 부스 위치 및 날짜별 프로그램 일정 제공
- **진입 조건:** GNB [Timetable & Map] 클릭
- **구성 영역:**
  - **지도 섹션:** 성수동/경복궁 지도 이미지 플레이스홀더, 부스 핀 (1마패 스틱존, 2마패 오브제존, 3마패 퍼퓸존)
  - **타임테이블 섹션:** 일자별 탭 (DAY 1, DAY 2, DAY 3), 타임라인 카드 (시간, 프로그램명, 조향사 세션)
- **인터랙션:** 부스 핀 클릭 시 `P-INFO-01-01-01` 팝업 호출

## 4. 반응형 레이아웃 및 접근성 요구사항

- **반응형 구극 (Breakpoints):**
  - Mobile: 320px ~ 767px (단일 열, 44px+ 터치 타겟)
  - Tablet: 768px ~ 1023px (2열 변환, 유연한 패딩)
  - Desktop: 1024px ~ 1440px+ (GNB 가로 노출, 컨테이너 Max-width 1200px)
- **웹 접근성 (WCAG 2.1 / KWCAG 2.2):**
  - 명암비: 텍스트 및 배경 명암비 4.5:1 이상 준수
  - 이미지 대체 텍스트: 모든 비주얼/플레이스홀더 `alt` 속성 명시
  - 키보드 접근성: `tabindex`, `focus-visible` 스타일 (보라색 아웃라인) 적용
  - ARIA 속성: `aria-modal="true"`, `aria-expanded`, `role="dialog"` 지정

## 5. 가정 사항 모음 (Assumptions Summary)

1. `[가정 1]` 부스 핀 클릭 시 노출되는 `P-INFO-01-01-01` 부스 향 노트 팝업은 입력 브리프에는 없으나 UX 완전성을 위해 추가함.
2. `[가정 2]` 예매자 편의를 위한 `P-PASS-01-03` 예매 내역 조회 팝업은 휴대폰 번호 기반 간이 조회 기능으로 설계함.
3. `[가정 3]` 1,000명 한정 얼리버드 티켓 매진 시 "대기 순번 알림 신청 모달"로 전환되는 예외 처리 추가함.
