# 사단 어사 출두 K-헤리티지 향 페스티벌 사이트맵 v2 (윤태양 - 대안 구조)

---

## 1. 프로젝트 개요
- **프로젝트명:** 사단 어사 출두 K-헤리티지 향 페스티벌 & 성수/경복궁 팝업 패스 웹사이트 (v2 대안 설계)
- **총괄 디렉터:** 윤태양 (사단 어사 출두 페스티벌 총괄 디렉터)
- **설계 핵심 컨셉 (Option B):** 오프라인 팝업 스탬프 투어 & 첩보 미션 중심의 **'디지털 모바일 컴패니언 (Digital Companion App)'** 특화 사이트맵
- **적용 매체:** 모바일 퍼스트 반응형 웹 (K-헤리티지 다크 네이비 `#0F1A30` & 샌드 골드 `#C5A059` 테마)

---

## 2. 기존 사이트맵 대비 차별화 설계 근거
1. **미션 수행형 IA 구조:** 단순 행사 소개에서 벗어나, 관람객이 '암행어사 첩보 미션'을 수행하는 듯한 몰입형 여정으로 직관화.
2. **듀얼 팝업존(성수·경복궁) 3D 인터랙티브 맵:** 성수 팝업존과 경복궁 시향존의 공간별 향 노트(1·2·3 마패)를 3D AR 핀으로 구별하여 현장 길잡이 기능 강화.
3. **Fast-Pass 티케팅 & 현장 모바일 첩보증(QR):** 1,000명 한정 얼리버드 Fast-Pass 예매 후 모바일 웰컴 키트 교환 QR 관람권을 마이페이지(가정)와 카카오 알림톡으로 실시간 연결.

## 6. 핵심 구분 명세 (v2 대안)

### 회원 상태별 영역 (가정)
- **비회원 (기본):** 3D 미션 영상 시청, 듀얼 시향 맵 탐색, Fast Pass 사전 예매 모달 신청
- **Fast-Pass 완료 회원 (가정):** 카카오 알림톡 링크 클릭 시 진입하는 '마이 어사 첩보증(P-MY-02)' 모바일 QR 키트 교환권

### 예외 페이지 (Exception)
- **404 페이지 없음 (P-ERR-404):** 잘못된 접근 시 Live Hub로의 안전한 원위치 복구
- **Fast-Pass 조기 매진 모달 (P-ERR-SOLD):** 1,000명 한정 수량 소진 시 취소표 대기 알림 폼 연결

### 주요 사용자 여정 (User Journey - v2 대안)
1. **여정 1 (Fast Pass 티케팅):** Live Hub ➔ [Fast Pass 예매] 모달 ➔ 날짜/인원 선택 ➔ 카카오 알림톡 수신 ➔ 예매 완료
2. **여정 2 (현장 첩보 미션):** Secret Mission 세계관 ➔ 듀얼 시향 맵 ➔ 성수/경복궁 마패 핀 향 노트 확인 ➔ 웰컴 키트 수령 안내
3. **여정 3 (예외 복구):** 매진 안내 ➔ 취소표 알림톡 신청 ➔ Live Hub 메인 복구
