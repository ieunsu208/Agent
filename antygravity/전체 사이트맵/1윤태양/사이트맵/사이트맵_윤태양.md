# 사단 어사 출두 K-헤리티지 향 페스티벌 사이트맵 (윤태양)

---

## 1. 프로젝트 개요
- **프로젝트명:** 사단 어사 출두 K-헤리티지 향 페스티벌 & 성수/경복궁 팝업 패스 웹사이트
- **총괄 디렉터:** 윤태양 (사단 어사 출두 페스티벌 총괄 디렉터)
- **제작 목적:** 얼리버드 패스 사전 예매 유치 및 한정판 웰컴 키트(어사 마패 뱃지/노리개 키링) 현장 수령 예약 모집
- **적용 매체:** 모바일 퍼스트 반응형 웹 (K-헤리티지 다크 네이비 `#0F1A30` & 샌드 골드 `#C5A059` 테마)

---

## 2. 설계 근거와 핵심 사용자 목표
1. **압도적 K-헤리티지 비주얼 경험:** 암행어사 출두 3D 모션 그래픽과 트레일러 비디오를 통해 독창적 축제 세계관을 선사.
2. **원스톱 팝업존 & 타임테이블 탐색:** 성수 팝업존 및 경복궁 시향존 인터랙티브 지도와 일자별(DAY 1~3) 프로그램 타임테이블 제공.
3. **1-Click 얼리버드 패스 예매:** 1,000명 한정 얼리버드 패스 티케팅 및 카카오톡 알림톡 자동 발행으로 현장 입장 유도.

---

## 3. 전역 내비게이션 구조 (GNB & FNB)
- **GNB (상단 고정):** SADAN FESTIVAL 로고 / 1. Festival Intro / 2. Timetable & Map / 3. Welcome Kit / 4. Pass Ticket / [얼리버드 예매] CTA
- **Sticky Bar (어사이드 · 모바일):** 얼리버드 한정 패스 실시간 카운트다운 & [1-Click 예매]
- **FNB (푸터):** 페스티벌 주최사, 오시는 길 약도, 약관/개인정보 처리방침, 공식 인스타그램 SNS

## 6. 핵심 구분 명세

### 회원 상태별 영역 (가정)
- **비회원 (기본):** 3D 비디오 시청, 부스 지도/타임테이블 탐색, 얼리버드 패스 예매 폼 작성
- **예매 완료 회원 (가정):** 카카오 알림톡 링크 진입 시 '내 티켓함(P-MY-01)' 현장 수령 QR 마패 관람권 조회

### 예외 페이지 (Exception)
- **404 페이지 없음 (P-ERR-404):** 유효하지 않은 경로 진입 시 홈 및 GNB 복구 안내
- **티켓 매진 모달 (P-ERR-SOLD):** 1,000명 얼리버드 한정 수량 소진 시 취소표 알림 신청 폼 노출

### 주요 사용자 여정 (User Journey)
1. **여정 1 (티케팅 중심):** 3D 히어로 비디오 ➔ [얼리버드 예매] 클릭 ➔ 날짜/인원 선택 모달 ➔ 카카오 알림톡 발송 ➔ 예매 완료
2. **여정 2 (부스 탐색 중심):** 시향 부스 지도 ➔ 성수 팝업 핀 터치 ➔ 아로마 향 노트 확인 ➔ 웰컴 키트 확인 ➔ 패스 예매
3. **여정 3 (예외 복구):** 매진 페이지 진입 ➔ 취소표 알림 신청 ➔ 메인 홈으로 원위치 복구
