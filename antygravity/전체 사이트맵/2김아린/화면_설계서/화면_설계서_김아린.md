## 3. 화면별 상세 사양 (Screen Specifications)

### 3.1 P-MAIN-01: 메인 홈
- **목적:** 한옥 공간 힐링 감성 전달 및 공간 향 매칭 퀴즈 / 정기구독 사전 신청 유치
- **진입 조건:** 자사몰 접속
- **종료 조건:** [나에게 맞는 향 찾기] 또는 [정기구독 신청] 클릭
- **구성 영역:**
  - **헤더:** SADAN WELLNESS 로고, GNB 메뉴 탭, [정기구독 신청] 버튼
  - **히어로:** 한옥 대청마루와 아침 햇살 비디오 배경, 힐링 캐치프레이즈
  - **바디 1 (퀴즈 요약):** 공간별 1분 향 매칭 퀴즈 미니 카드 (침실, 서재, 거실)
  - **바디 2 (스마트 디퓨저):** 영구 사용 한옥 기와 모티브 디바이스 preview
  - **바디 3 (임상 뇌파):** 숙면 임상 알파파 수치 시각화 수치 뱃지
  - **바디 4 (정기구독):** 매월 계절별 아로마 카트리지 정기 배송 플랜 가격표
  - **어사이드:** 우하단 고정 [4종 무료 시향 캡슐 신청] 스티키 뱃지
  - **푸터:** 브랜드 정보, 구독 해지 정책, 임상 센터 안내, SNS

---

### 3.2 P-TEST-01-01: 1분 공간 퀴즈 모달
- **목적:** 사용자 공간 환경과 취향을 분석하여 맞춤 아로마 레시피 생성
- **진입 조건:** `P-TEST-01`에서 [퀴즈 시작] 클릭
- **종료 조건:** 3개 문항 답안 선택 완료
- **UI 요소 & 인터랙션:**
  - **Q1 (공간 선택):** 침실 / 서재 / 거실 중 택 1 (카드 버튼 선택)
  - **Q2 (주요 목적):** 숙면 & 수면 장애 완화 / 집중력 강화 / 일상 스트레스 정화
  - **Q3 (선호 향 노트):** 오리엔탈 묵향 / 생쑥 & 다도 차 / 은은한 침향
  - **진행률 바:** Step 1/3 -> 2/3 -> 3/3 프로그레스 애니메이션
- **유효성 검사:** 각 단계별 문항 미선택 시 [다음] 버튼 비활성화

---

### 3.3 P-SUB-01-01: 카트리지 정기구독 사전 신청 폼
- **목적:** 사전 정기구독 신청 정보(신청자 이름, 휴대전화, 배송지) 수집
- **진입 조건:** GNB [구독 신청] 또는 퀴즈 결과에서 [이 레시피로 구독하기] 클릭
- **종료 조건:** [사전 신청 확정] 클릭
- **UI 요소 & 유효성 검사:**
  - **이름:** 필수 입력 (미입력 시 "성함을 입력해 주세요" 에러 표시)
  - **휴대전화:** 필수 입력, 숫자 10~11자리 Regex 검사 (불일치 시 "올바른 휴대전화 번호를 입력해 주세요")
  - **배송지 주소:** 필수 입력 (우편번호 검색 버튼)
  - **카트리지 플랜 선택:** 계절별 카트리지 4종 세트 (기본 선택)
  - **혜택:** 사전 신청 고객 무상 디바이스 증정 체크박스 자동 선택

## 4. 반응형 레이아웃 및 접근성 요구사항

- **PC (Desktop >= 1200px):** 12단 그리드, Split 2단 배치가 포함된 풍부한 레이아웃
- **Tablet (768px ~ 1199px):** 2열 그리드 및 햄버거 내비게이션 전환
- **Mobile (< 768px):** 1열 수직 카드 레이아웃, 하단 스티키 바 최적화
- **접근성 (WCAG 2.1 AA):**
  - 명암비 4.5:1 이상 준수 (오트밀 베이지 `#F4F0EA` 상의 차콜 묵색 `#2A2623` 텍스트)
  - 비디오 자동 재생 시 음소거 기본 설정 및 재생/일시정지 버튼 제공
  - 모든 폼 요소에 `<label>` 및 `aria-describedby` 연결

## 5. 설계 가정 사항 (Assumptions)

1. [가정] 정기구독 사전 신청자는 정식 론칭 시 무상으로 스마트 디퓨저 디바이스(시가 18만원 상당)를 제공받는다.
2. [가정] 무료 시향 캡슐 4종 신청은 동일 휴대전화 번호 기준 1인 1회로 제한한다.
3. [가정] 정기구독 완료 시 카카오 알림톡으로 알림 메시지와 현장/배송 QR 코드가 발송된다.
