[4. 메인페이지 스토리보드 최종 프롬프트 (Antigravity 버전)]

현재 작업 폴더를 기준으로 아래 작업을 수행해줘.

- 클라이언트 리서치 입력 파일: [가상 클라이언트\클라이언트 모음\신규_클라이언트1_윤태양.md]
- 브랜드 웹페이지 레퍼런스 분석: [메모\master_references1.txt] 및 [메모\master_references2.txt]
- 사이트맵 입력 파일: [전체 사이트맵\1윤태양\사이트맵\사이트맵_윤태양.md]
- 서비스 흐름도 입력 파일: [전체 사이트맵\1윤태양\서비스_흐름도\서비스_흐름도.md]
- 화면 설계서 입력 파일: [전체 사이트맵\1윤태양\화면_설계서\화면_설계서_윤태양.md]
- 추가 참고 프롬프트: [프롬프트\Antigravity 프롬프트.txt]
- 결과물 저장 폴더: [스토리보드 결과]

입력 파일을 모두 읽고 폴더 안의 설계 파일들과 브랜드 웹페이지 레퍼런스 분석 데이터를 기반으로 메인페이지(P-MAIN-01) 스토리보드를 작성해줘. Figma를 생성하거나 수정하지 말고, CLI에서 바로 확인하고 다른 도구에서도 재사용할 수 있는 로컬 파일로 결과물을 만들어줘.

다음 파일을 UTF-8 인코딩으로 생성해줘.

1. `메인페이지_스토리보드.md`
   - 프로젝트 개요 및 선택된 레퍼런스 레이아웃 아키타입(Type 1~6) 구조 표
   - 화면 1개당/섹션 1개당 상세 표 형식 스토리보드 명세 (화면 ID, 영역명, 노출 조건, UI 구성 요소, 표시 데이터, 사용자 행동, 시스템 처리, 이동 대상)
   - 상태별 UI 표(기본/로딩/오류/완료) 및 접근성/반응형 명세 표
2. `메인페이지_스토리보드.html`
   - 외부 라이브러리 없이 브라우저에서 단독 실행 가능한 회색 박스/텍스트 중심 스토리보드 뷰어
   - 획일적 상하 나열 템플릿 배제 및 선택된 레퍼런스 아키타입에 최적화된 고유 CSS Grid/Flex 쉘 구현
3. `스토리보드_목록.json`
   - 각 스토리보드 표 항목의 `id`, `name`, `section`, `uiComponents`, `userActions`, `systemLogic`, `nextScreen`을 포함한 유효한 JSON
4. `메인페이지_스토리보드.txt` 및 `최종_프롬프트.txt`
   - 문서 및 텍스트 뷰어용 텍스트 형식 스토리보드 명세서 및 최종 수행 프롬프트

작성 규칙:

- [획일적 템플릿 사용 전면 금지]: 모든 클라이언트에 동일한 Header-GNB-Hero-3열카드-Aside 구조 사용을 금지하고, 브랜드 분석 레퍼런스 웹페이지(이솝, 르라보, SW19, 탬버린즈, 논픽션, 팝업 플랫폼 등) 중 클라이언트 목적에 맞는 레이아웃을 1:1 매핑하여 구현해줘.
- [클라이언트 맞춤 제품 쇼케이스 필수 배치]: 메인 상단 핵심 영역에 실물 제품/키트/굿즈 쇼케이스를 회색 박스로 전면 배치해줘.
- 메인페이지의 각 구역을 화면 1개당/섹션 1개당 완벽한 독립 표(Table) 형식으로 명확히 구별해서 작성해줘.
- 공통 헤더, 푸터, 내비게이션과 반복 컴포넌트는 일관되게 적용해줘.
- 입력 파일에 없는 상세 정책은 `가정`으로 표시하고 스토리보드에 따로 모아줘.
- HTML의 모든 내부 이동, 주요 버튼, 반응형 레이아웃과 JSON 문법을 검사해줘.
- 작업 완료 후 생성한 파일의 상대 경로와 각 파일의 용도를 짧게 출력해줘.
