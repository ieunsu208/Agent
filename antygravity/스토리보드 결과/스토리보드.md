## 3. 핵심 디자인 & 롱 스크롤 레이아웃 생성 규칙

### 📜 1. 8개 섹션 분량 참고 & 대형 구도(Layout Architecture) 차별화 원칙
- **섹션 수 & 길이 참고:** 8개 이상의 섹션 수와 세로 롱 스크롤 분량은 스토리보드의 '풍부한 콘텐츠 양과 깊이'를 보장하기 위한 규격 참고용 기준입니다.
- **상하 세로 블록 고정 금지:** 모든 스토리보드가 동일한 상하 세로 나열형(헤더-GNB-히어로-카드-푸터) 템플릿 구조로 나오는 것을 전면 금지합니다.
- **5대 대형 구도(Architecture System) 필수 적용:** 화면 설계서에 정의된 클라이언트 비즈니스 성격에 따라 아래 5가지 대형 구도 중 하나를 선택하여 화면 전체 뼈대(Grid Shell)를 100% 다르게 작성합니다.
  - **Type A (비대칭 벤토 그리드 구도):** 화면 전체가 2x2/3x3 대형 벤토 타일 모듈로 파격 쪼개진 그리드 구조
  - **Type B (인터랙티브 스텝 위저드 & 타임라인 구도):** 가로/세로 단계별 연결선과 타임라인 피커가 중심이 되는 프로세스 구조
  - **Type C (50:50 듀얼 Split 패널 구도):** 좌측 50% 고정 뷰포트와 우측 50% 독립 스크롤 폼으로 양분된 2열 분할 구조
  - **Type D (좌측 세로 고정 사이드바 Navigation + 럭셔리 매거진 룩북 구도):** 상단 GNB 바를 전면 삭제하고, **좌측 280px에 세로 고정 사이드바**를 둔 뒤 우측에서 오버랩 갤러리가 전개되는 매거진 구조
  - **Type E (앱 / 티켓팅 대시보드 뷰포트 구도):** 일반 웹 템플릿을 깨고, [지점 스위치] + [좌측 캘린더 타임슬롯 그리드] + [우측 스마트폰 QR 패스 뷰어] 중심의 예매 전용 2열 대시보드 구조

### 🎁 2. ★ [필수] 메인 제품 전시 쇼케이스 (Product Showcase Section) 전면 배치
- Hero 섹션 직후(`SEC-03`) 또는 메인 상단 핵심 영역에 각 클라이언트 비즈니스 모델에 특화된 실물 제품/키트/패키징을 각 레이아웃 아키타입 구도에 맞춘 회색 박스 쇼케이스로 전면 배치합니다.

### 🚫 3. 자바스크립트(JS) 전면 제외 규칙
- `<script>` 태그, Inline JS 이벤트(`onclick`, `onmouseover` 등), 외부 JS 라이브러리(jQuery, React, Vue 등) 생성을 전면 금지합니다.
- 오직 순수 **HTML5 시맨틱 구조**와 **Vanilla CSS3 (Flexbox & CSS Grid)**만으로 레이아웃과 반응형 시각화 인터페이스를 구현합니다.

### ⛔ 4. #금지 디자인 (Forbidden Design Tropes)
작성 시 아래의 금지 디자인 패턴을 엄격히 배제합니다.
- **금지:** 다크 테마 배경에 보라색/바이올렛 계열 폰트 및 고휘도 네온 글로우 테두리
- **금지:** CSS 그래디언트 텍스트 Fill (Text Gradient Fills)
- **금지:** 의미 없는 아이콘이 무분별하게 채워진 벤토 박스 (Bento box) overuse
- **금지:** 3중 이상 과도하게 중첩된 카드 레이아웃 (Nested Cards)
- **금지:** 외부 이미지 URL 및 실제 사진 파일 삽입 (모두 CSS 그래픽 요소 및 회색 플레이스홀더 영역으로 대체)

### 🔳 5. #출력형태 (Grey-box & Text Only Wireframe)
- **색상 팔레트:** 무채색 및 회색 톤으로만 제한
  - 백그라운드 & 카드: `#ffffff`, `#f8f9fa`, `#e9ecef`, `#dee2e6`
  - 테두리 & 구분선: `#ced4da`, `#adb5bd`
  - 폰트 & 텍스트: `#212529`, `#495057`, `#6c757d`
- **1:1 회색 박스 매핑:** 화면 설계서에 정의된 10대 이상 콘텐츠와 10대 이상 기능 요소가 8개 섹션 상의 회색 박스, 입력 폼, 슬라이더, 아코디언 UI로 100% 매핑 렌더링되어야 합니다.
